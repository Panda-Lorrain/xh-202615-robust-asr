# 使用说明

> 标准化推理脚本 `code/submit_infer.py`:吃 enrollment + recognition → 输出 `result.json` + `timing.json`。
> 纯 stdlib subprocess 顶层编排,零侵入复用 `noise_classify` / `se_denoise` / `enroll_infer` / `llm_reject`。

---

## 1. 环境要求

### 硬件
- **GPU**:NVIDIA 8GB+(本机 RTX 4060 Laptop 8GB 已跑通;**官方评测在 L20 48GB**)
- 磁盘:权重 + 缓存约 15GB(全落 E 盘,禁 C 盘)

### 软件栈(3 个独立 venv,依赖冲突**不可合并**)

|---|---|---|---|
| `.venv`(主) | `code/.venv/` | enroll_infer / noise_classify / DiariZen | torch 2.5.1+cu124 / transformers 4.42.4 / DiariZen |
| `.venv_se` | `code/.venv_se/` | se_denoise / DeepFilterNet3 | df-simple / DeepFilterNet3 |

## 3. 运行推理(`submit_infer.py`)

### 完整参数(读自 `argparse`)
| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `--pairs` | path | — | **二选一输入**:`[{enrollment, recognition}, ...]` manifest(一对一) |
| `--enrollment` | path | — | **二选一输入**:目标说话人参考 wav(需配 `--recognition-folder`) |
| `--recognition-folder` | path | — | 识别 wav 目录(配 `--enrollment`,一对多) |
| `--no-se` | flag | off | 跳过 SE 条件化降噪 |
| `--no-llm` | flag | off | 跳过 LLM 拒识(**保底必带**,关 LLM 双优 RTF + RR) |
| `--sim-thr` | float | **0.2** | 声纹拒识阈值(**B 集统一 0.27**, T27 对抗验证推荐) |
| `--strategy` | enum | `llm_or_sim` | 融合策略:**保底用 `sim_only`**(⚠️ `llm_or_sim` 实为 AND,LLM 只减拒不加拒) |
| `--asr-backend` | enum | `dicow` | **ASR 后端:`vanilla`(主线, CER 减半) / `dicow`(已证伪 fallback)** |
| `--content-gate` | flag | off | 开 content_gate:sim≥thr 的 accept 若转写非有效家居指令则加拒(hold-out val +2.5 分证泛化, 默认关; `run_baodi` 用 `BAODI_GATE=1` 开) |
| `--seed` | int | 42 | 全局种子(透传 4 子进程, 可复现性) |
| `--device` | str | `cuda:0` | 推理设备 |
| `--out-dir` | path | `code/submit_out` | 输出目录 |
| `--work-dir` | path | `<out-dir>/_work` | 中间产物 |
| `--limit` | int | 0(全部) | 只处理前 N 条(烟雾测试用) |

`--pairs` 与 `--enrollment` **互斥必填其一**;`--enrollment` 需配 `--recognition-folder`。

> ⚠️ **保底守卫**(memory `baodi-config-no-llm`):裸调 `submit_infer.py` 默认 flag(LLM ON / sim_thr=0.2 / strategy=llm_or_sim)→ RTF~1.0 + neg RR~0.77 双崩。**提交必须用 `code/run_baodi.sh`** 锁死 `--no-llm --sim-thr --strategy sim_only --asr-backend vanilla`;统一 thr=0.27 < 守卫阈值 0.35,故 B 集必经 `run_baodi.sh B`(或显式 `export BAODI_OK=1`)。

### 标准用法

**⭐ 提交入口(B 集混合集,统一 thr=0.27,锁死关 LLM + vanilla + sim_only)**:
```bash
bash code/run_baodi.sh B 0.27
# 等价于: code/submit_infer.py --pairs code/B_pairs_datasetA.json --out-dir code/out_B_baodi \
#           --no-llm --sim-thr 0.27 --strategy sim_only --asr-backend vanilla
# 开 content_gate: BAODI_GATE=1 bash code/run_baodi.sh B 0.27
# 切 dicow fallback/答辩对比: BAODI_BACKEND=dicow bash code/run_baodi.sh B 0.27
```
A 集分 thr 初评(已知 label): `bash code/run_baodi.sh pos [thr]` / `bash code/run_baodi.sh neg [thr]`(默认 thr=0.4)。

**A. 一对多(同一 enrollment,一批识别音频)**:
```bash
source code/setenv.sh && export HF_HUB_OFFLINE=1
code/.venv/Scripts/python.exe code/submit_infer.py \
  --enrollment <enr.wav> \
  --recognition-folder <rec_dir> \
  --out-dir <out>
```

**B. 一对一(enrollment 与 recognition 配对,manifest)**:
```bash
code/.venv/Scripts/python.exe code/submit_infer.py \
  --pairs <manifest.json> \
  --out-dir <out>
```
`manifest.json` 格式:
```json
[{"enrollment": "path/to/enr.wav", "recognition": "path/to/rec.wav"}, ...]
```

### 降级 / 快测
```bash
# 跳 SE(纯 enroll+LLM):
... --no-se
# 跳 LLM(纯声纹拒识,显存不足时兜底):
... --no-llm
# 烟雾测试前 3 条:
... --limit 3
# 纯声纹策略:
... --no-llm --strategy sim_only
# vanilla 后端(主线, CER 减半):
... --asr-backend vanilla
# 开 content_gate(转写内容有效性二次拒):
... --content-gate
```

> **提交归一 SSOT**(`code/text_utils.py`, 2026-07-08 workflow④ 补):输出 text 经 `to_simplified`(zhconv 繁→简)+ `digit_postproc`(cn2an 阿拉伯→中文数字, 对齐 ref 口径)后写入 result.json/submission.json。⚠️ **`cn2an`/`zhconv` 必须安装**(`uv pip install -r code/requirements.txt`),否则缺包静默 graceful 跳过 → CER 0.595 实际回 0.661(数字后处理收益全丢)。缺包现已改 RuntimeWarning(不再静默)。

### 输出
- `<out>/result.json` — 每条结果(见 §4)
- `<out>/timing.json` — 端到端耗时(overall_rtf + phases + per_utt)
- `<out>/_work/` — 中间产物(noise_est / se_out / enroll_g* / llm_out,可删)

控制台末尾打印汇总:`N 条 (M 拒识) / overall_rtf=X (audio=Ys wall=Zs) / phases={...}`。

### 官方提交格式(`code/to_submission.py` 转换)

`result.json` + pairs manifest → 官方提交 JSON(2026-07-06 主办方确认 schema):
```jsonc
{
  "result": {
    "results": [
      {"id": "cmd_3", "content": "把空调调到二十六度", "label": "accept", "cer": 0.000}
      // id=测试音频名(去 uttN_ 前缀) / content=归一后转写(rejected 时 "") /
      // label=accept|reject(由 sim_thr) / cer=pos 算(rejected=1.0, neg="")
    ],
    "final_cer": 0.595,   // pos 累计池(主办方口径: NFKC+lower+去P*+editdistance)
    "duration": 3498.123  // batch=1 逐条推理总秒数(从 timing.json duration_infer_sec 累加)
  }
}
```
```bash
code/.venv/Scripts/python.exe code/to_submission.py \
  --result-json <out>/result.json --pairs <pairs.json> \
  [--duration <batch=1 总秒数>] [--out <out>/submission.json]
```

## 4. 输入输出格式

### `result.json`
```jsonc
{
  "task_id": "XH-202615",
  "generated_at": "2026-07-01T...",
  "config": {"se": true, "llm": true, "strategy": "llm_or_sim", "sim_thr": 0.2, "device": "cuda:0"},
  "n_utt": 3,
  "results": [
    {
      "utt_id": "rec_001",
      "enrollment": "path/enr.wav",
      "recognition": "path/rec_001.wav",
      "text": "请把客厅的空调温度调到二十六度",   // rejected=true 时为 ""
      "rejected": false,
      "score": 0.4401,                          // = max_sim
      "max_sim": 0.4401,
      "llm_verdict": "accept",                  // --no-llm 时为 null
      "noise_type": "white",                    // 谱平坦度估计
      "atten_lim_db": 0,                        // SE 降噪强度
      "diar_fail": false
    }
  ]
}
```

**字段语义**:
- `rejected=true` 时 `text=""`(拒识不输出转写);`score=max_sim`。
- `llm_verdict`:`accept` / `reject`(`--no-llm` 时为 `null`,融合退化为 `sim_only`)。
- `noise_type` / `atten_lim_db`:由阶段0 `noise_classify` 谱估计产生。**`--no-se` 时为 `null`**(SE 跳过 → 未估噪声,无 `atten_lim_db` 可填);启用 SE 时为 `"white"`/`"pink"`/`"babble"` 与 `0`/`6`。
- `diar_fail=true`:恶劣音频触发 pyannote reconstruct 边界 crash,enroll_infer 已 try/except 跳过(该条 `rejected=true`、`text=""`)。

### `timing.json`
```jsonc
{
  "device": "cuda:0",
  "n_utt": 3,
  "total_audio_sec": 8.2,
  "total_wall_sec": 35.7,
  "overall_rtf": 4.3537,        // = wall / audio
  "phases": {
    "noise_classify": {"wall_sec": 0.5},
    "se": {"wall_sec": 12.3, "n": 3},
    "enroll_diar_dicow": {"wall_sec": 20.1, "mean_rtf": 0.06},
    "llm": {"wall_sec": 2.8}
  },
  "per_utt": [{"utt_id": "rec_001", "audio_sec": 2.7, "wall_sec": null, "rtf": 0.058}, ...]
}
```

## 5. 常见报错与兜底

| 报错 | 原因 | 解决 |
|---|---|---|
| `diar crash: negative dimensions are not allowed`(pyannote reconstruct 边界) | 极端短音频/恶劣噪声 | `enroll_infer` 已 try/except 跳过该条(`diar_fail=true`),pipeline 不中断 |
| DiCoW 输出英文 / 中文转写垃圾 | HF 缓存被清,language 死代码 bug 复现 | 重打补丁:`code/.venv/Scripts/python.exe code/apply_dicow_langfix.py` |
| LLM venv 显存不足(OOM) | Qwen2.5-3B + DiCoW 同卡 8GB 紧张 | 用 `--no-llm` 兜底(退化为纯声纹 `sim_only` 拒识),或 `--device cuda:1` 分卡 |
| HF 直连卡死 | 网络问题 | `source code/setenv.sh` 设镜像 + 代理;权重已在 `E:/hf_cache`,设 `HF_HUB_OFFLINE=1` |
| `modelscope import` 挂起 | modelscope 1.37 + Win + torch2.5 兼容问题 | 不影响主线(主线用 wespeaker 非 CAM++);CAM++ 仅边缘部署备用 |

## 6. 评测(配合 `eval_metrics.py` / `eval_full_test.py` / `eval_datasetA.py`)

> ⚠️ **`eval_metrics.py` 无 CLI**(`__main__` 仅自测 print, 不接受 `--result/--manifest/--out`)。复用方式:
> - **import 函数**:`from eval_metrics import cer, cer_pool, cer_official, rejection_metrics`(累计池 `cer_pool` / 官方口径 `cer_official` 已照抄主办方脚本, 4-agent 对抗验证逐行等价)
> - **包装脚本**:`eval_full_test.py`(全量分解 overlap/SNR/noise + correct_rate)/ `eval_datasetA.py`(A 集 pos CER + neg RR, 繁简归一)/ `recompute_official_cer.py`(官方口径全量重算, 产物 `recompute_official_cer.json`)

```bash
# A 集评测(pos CER + neg RR, 对照 datasetA ground truth):
code/.venv/Scripts/python.exe code/eval_datasetA.py <out>/result.json code/pos_pairs_datasetA.json

# 官方口径全量重算(转写 / thr 工作点 / sim 分桶 / 数字, 累计池):
code/.venv/Scripts/python.exe code/recompute_official_cer.py

# 全量分解(overlap/SNR/noise 分档 + correct_rate, 复用 cer()):
code/.venv/Scripts/python.exe code/eval_full_test.py <out>/result.json <gt_manifest.json>
```

**官方 CER 口径**(2026-07-08 主办方脚本坐实, 详见 memory `official-scoring-spec`):
- 归一化:`unicodedata.NFKC + lower + strip + 去所有 Unicode P* 标点和空白`(含内部空格)。**不繁简归一、不数字归一**。
- 聚合:**累计池** total_errors/total_chars(`editdistance.eval`, 非逐条平均)。
- 拒识条:pred 空 → errors=len(ref) → CER=1.0 天然(pos 隐含允许被拒, 无额外惩罚)。
- 排名公式:`TotalScore = w1*(1−CER) + w2*RR`(线性, per-sample 不封顶)。

详见 [`测试验证方案.md`](测试验证方案.md)。
