## 1. 评测指标(对齐评分维度)

| 评分维度 | 权重 | 本项目指标 | 计算方式 |
|---|---|---|---|
| 目标 CER | 40% | 字符级 CER(**官方口径累计池**) | `eval_metrics.cer_official`(NFKC+lower+去P*+editdistance);**拒识条计 CER=1.0**(主办方确认 pos 隐含允许拒) |
| 拒识率 | 40% | target-absent 集真实拒识率(RR)+ target-present 集误拒率(FRR) | RR=正确拒/应拒总数;FRR=误拒/应转总数 |
| 推理效率 | 20% | 推理时间 10% + 内存 10% | `timing.json:overall_rtf`(**L20 batch=1** 重测;本机 4060 仅参考) |

**关键约定(2026-07-08 主办方坐实)**:
- **排名公式**:`TotalScore = w1*(1−CER) + w2*RR`(线性, per-sample 不封顶, CER 可>1);w1=w2 最可能(0.4/0.4)→ thr=0.27 定稿。
- CER 口径:`normalize_text`(NFKC + lower + strip + 去所有 Unicode P* 标点和空白) + 累计池 total_err/total_char(editdistance 库)。**不繁简归一、不数字归一**。
- **被系统拒识的 target-present 条**计 CER=1.0(等于完全漏转, 无额外惩罚)→ 拒识太严会同时伤 CER 和 FRR。
- 拒识率口径:**target-absent 集真实拒识率(越高越好)** + **target-present 集误拒率(越低越好)**,两者需同时报。

## 2. 评测脚本

| 脚本 | 用途 |
|---|---|
| `code/eval_metrics.py` | **无 CLI**(`__main__` 仅自测); 提供 `cer`/`cer_pool`/`cer_official`/`rejection_metrics`/`compute_rtf` 函数, 供其他脚本 import |
| `code/eval_datasetA.py` | A 集评测: pos CER(误拒=1.0) + neg RR + zhconv 繁简归一 |
| `code/recompute_official_cer.py` | **官方口径全量重算**(转写/thr 工作点/sim 分桶/数字, 累计池), 产物 `recompute_official_cer.json` |
| `code/eval_full_test.py` | 全量分解(overlap/SNR/noise 分档 + correct_rate, 复用 `cer()`) |
| `code/scan_unified_thr.py` | 统一 thr 选点(bootstrap CI + 诊断 + 真压力), 产物 `scan_unified_thr.json` |
| `code/fuse_eval.py` | 多策略融合扫最优工作点(仿真期, 评测用非推理) |
| `code/build_reject_set.py` | 造 target-absent 集(仿真期 72 条) |

**融合策略**(`submit_infer.py --strategy`):
- `sim_only`(保底):拒 iff `max_sim < sim_thr`
- `llm_only`:拒 iff `llm ≠ accept`
- `llm_or_sim`(默认, ⚠️ 实为 AND):拒 iff `(llm ≠ accept) AND (max_sim < sim_thr)` — LLM 只减拒不加拒

## 3. 当前结果(datasetA 全量真测 1362 条,官方口径)

> ⭐ **2026-07-08 主办方 CER 口径脚本到手坐实**(NFKC + lower + 去所有 Unicode P* 标点和空白 + 累计池 total_err/total_char, editdistance 库; 不繁简不数字)。以下数字均来自 `code/recompute_official_cer.py` 重算(提交归一后, 累计池), 详见 `recompute_official_cer.json` + `RESULTS.md` T23/T24/T27。
> 仿真 450 条旧数字(CER 4.27/2.504)已**全部过时**, 移至 §3.6 历史归因参考。

### 3.1 转写 CER(vanilla 主线 vs DiCoW 已证伪 fallback,1362 条 pos)

| 后端 | 转写 overall CER | correct(CER<0.5) | near_perfect(CER<0.1) | 英文幻觉率 |
|---|---|---|---|---|
| **vanilla(主线)** | **0.595** | **48.8%** | 26.3% | **0.6%** |
| DiCoW(已证伪 fallback) | 1.189 | 31.4% | 14.9% | 18.7% |

- **反 cascaded 突破**:DiCoW 的 FDDT/STNO 条件化在极重 babble 下【反作用】(sim 0.2–0.4 桶 CER 1.5–1.6、英文幻觉 18.7%), 改用 vanilla Whisper-large-v3-turbo + 声纹切 target timeline, CER 几乎减半(原项目口径逐条均 0.664 → 官方口径累计池 0.595)。
- 机制:diar+wespeaker 选 target(复用 `enroll_infer`)→ 切 target timeline 段(含重叠区)拼接 → vanilla Whisper 转写(去掉 stno_mask/FDDT 条件化)。

### 3.2 thr 工作点(含拒累计池,B 集统一 thr=0.27)

| thr | vanilla 含拒 CER | vanilla correct | dicow 含拒 CER | Δ(dicow−vanilla) |
|---|---|---|---|---|
| 0.20 | 0.657 | 0.384 | 1.181 | −0.524 |
| **0.27(B 集统一)** | **0.703** | 0.318 | 1.129 | −0.425 |
| 0.35 | 0.783 | 0.217 | 0.899 | −0.116 |
| 0.40(A 集分 thr 保底) | 0.825 | 0.156 | 0.912 | −0.087 |

- **统一 thr=0.27**(T27 5-agent 对抗验证推荐, bootstrap CI [0.26,0.29]): B 集按 FAQ C9 不预分 pos/neg → 必须单一 thr; 0.27 在 40:40 线性估算下最优(与 0.28 不可分取 pos 占优)。
- **caliber-A 已彻底解除**(2026-07-08 主办方确认): pos 隐含允许被拒(拒=CER1.0 无额外惩罚) + 排名公式 `TotalScore=w1*(1−CER)+w2*RR`(线性无惩罚, per-sample 不封顶) → thr=0.27 可用。

### 3.3 sim 分桶(反 cascaded 铁证, 1362 条 pos)

| sim 桶 | n | vanilla CER | dicow CER | Δ(dicow−vanilla) |
|---|---|---|---|---|
| [0.0, 0.2)(死区) | 397 | 0.784 | 1.030 | −0.246 |
| **[0.2, 0.3)** | 332 | **0.659** | **1.609** | **−0.950** |
| **[0.3, 0.4)** | 336 | **0.641** | **1.522** | **−0.881** |
| [0.4, 1.0)(轻 babble) | 286 | 0.280 | 0.638 | −0.358 |

- **条件化最毒的证据**:sim[0.2,0.3) 与 [0.3,0.4) 桶 DiCoW CER 1.5–1.6, 远高于整体 1.189, 是 DiCoW 最毒桶; vanilla 同桶 0.64–0.66。极重 babble 下 STNO 概率对 target 判别失效 → FDDT 把错乱权重焊进 Whisper 输入, 比不条件化更糟。
- **死区归因(P1 oracle POC 坐实)**:sim<0.2 死区(29%)是 babble 摧毁 mel 的物理极限(单 speaker 控制组 n=18 CER 0.436 + miss 声纹反向 20/20), 非选择器工程缺陷 → 不投 CAM++/US-PVAD 声纹强化。

### 3.4 拒识侧(neg 474 条 + pos 误拒)

| 测试集 | thr | 指标 | 结果 | 说明 |
|---|---|---|---|---|
| neg(target-absent, 474 条) | 0.27(统一) | 真实拒识率 RR | **90.5%** | sim 分布 med 0.116, thr0.27 漏拒 ~9.5%(多新闻/英文/乱码) |
| neg | 0.40(A 集分 thr) | RR | **98.5%** | thr 升 → RR 升但 pos correct 降(31%@0.2→14%@0.4) |
| pos(1362 条) | 0.27 | 误拒率 | ~50% | pos sim med 0.283 ≈ thr → 约半数被误拒(CER=1.0); pos/neg sim [0,0.4] 严重重叠, 纯 thr 破不了 |
| content_gate(hold-out val) | 0.27 | ΔRR / ΔTS | +0.045 / **+0.025(+2.5 分)** | 转写内容有效性二次拒; 10 seed 10/10 全正; 默认关(BAODI_GATE=1 开) |

## 4. 真实 A 集评测流程(已执行, 2026-07-04 真测 + 2026-07-08 口径重算)

> ✅ A 集已到手并完成全量真测(pos 1364 / neg 474, 单通道 16k/16bit mono)。以下为已执行流程, B 集到手后按同流程(无 ref, 主办方算 CER)。

1. **准备 manifest**:`code/make_pairs_from_datasetA.py` 把 A 集 enrollment + recognition 配对成 `--pairs` manifest(含 label, gitignore 不入库)。
2. **跑标准化推理**(保底入口, 锁死关 LLM + vanilla + sim_only):
   ```bash
   # A 集分 thr(pos/neg 分开跑, utt_id 冲突)
   bash code/run_baodi.sh pos 0.4    # pos 全转写 thr=0.4
   bash code/run_baodi.sh neg 0.4    # neg RR 98.5%
   # B 集统一 thr(混合 pos/neg 无 label, T27 推荐 0.27)
   bash code/run_baodi.sh B 0.27
   ```
3. **算指标**(官方口径累计池):
   ```bash
   code/.venv/Scripts/python.exe code/eval_datasetA.py code/out_pos_baodi/result.json code/pos_pairs_datasetA.json
   code/.venv/Scripts/python.exe code/recompute_official_cer.py    # 全量重算 → recompute_official_cer.json
   ```
4. **转官方提交格式**:`code/to_submission.py`(归一 SSOT: to_simplified + digit_postproc)。
5. **报效率分**(L20 峰值显存 + overall_rtf batch=1, 读 `timing.json`;⚠️ 本机 4060 数字仅参考, L20 待测)。

## 6. 局限声明(诚实)

1. **L20 端到端耗时未真测**:本机仅 4060, RTF 0.2543 是 4060 数字, L20 会更快但需租 AutoDL L40 验证(风险 12)。
2. **边缘部署目标硬件未定义**:赛事方未定义终态硬件(MCU/网关/服务器), 当前方案服务器级, MCU 级需量化蒸馏(风险 13)。
3. **100% 重叠单通道死区**:两人同帧说话、单麦克风无方向信息, diarization 退化为把主导声归到多 speaker → 单通道确认, 空间路线全弃, 靠 sim_thr 拒识兜底(诚实承认最薄弱处)。
4. **死区是物理极限**:P1 oracle POC 证 sim<0.2 死区(29%)是 babble 摧毁 mel 非选择器工程缺陷(单 spk 控制组 n=18 CER 0.436), 声纹强化(CAM++/US-PVAD)收益封闭已证伪。
5. **pos/neg sim 严重重叠**:pos sim med 0.283 / neg sim med 0.116, [0,0.4] 重叠 → 纯 thr 破不了, 统一 thr0.27 是 trade-off(pos correct 31.8% / neg RR 90.5%), 分 thr oracle 损失 6.46 分是 B 集无 label 的代价。
6. **仿真噪声谱 ≠ 真实远场**:仿真 450 条(mimo-tts + 程序噪声)仅作归因参考, 已被真测 1362 条取代(§3.6)。
