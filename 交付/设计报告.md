# XH-202615 技术设计方案

> 美的集团发榜《复杂交互场景的抗干扰语音指令识别技术》(XH-202615)
> 本文档描述**实际已实现的方案**(截至 T27 + 官方口径坐实 / 2026-07-08),非理想态规划。理想态组件(CAM++/Personal VAD)在文中明确标注为"未用/证伪"。⭐ 主线 ASR 后端 2026-07-06 Phase 1 已从 DiCoW 改为 vanilla + target extraction。

---

## 1. 问题定义与评分

- **任务**:给定目标说话人的**唤醒音频(enrollment)**,在带噪(SNR −5~5 dB)+ 多人重叠(≤2 人,重叠率 0–100%)的**识别音频(recognition)**中,只转写目标说话人的指令、拒识非目标干扰。
- **评分维度**:
  - 目标 CER(字符错误率) — 40%
  - 拒识率(目标缺席时真实拒识 / 目标在场时误拒) — 40%
  - 推理效率(RTF、峰值显存,官方在 **L20 GPU** 上评测) — 20%
- **运行约束**:推理脚本需在 L20 上吃 enrollment + recognition → 输出标准化 `result.json` + `timing.json`。

---

## 2. 总体架构(实际实现)

> ⭐ **2026-07-06 Phase 1 突破 + 2026-07-08 口径坐实**:主线 ASR 后端从 DiCoW(FDDT 条件化)改为 **vanilla Whisper-large-v3-turbo + target extraction**(DiCoW 条件化在极重 babble 下【反作用】已证伪, 降为 fallback)。以下数据流为当前主线。

**数据流**(已实现于 `code/submit_infer.py`,4 阶段 subprocess 编排):

```
recognition.wav
   │
   ├─[阶段0] noise_classify (谱平坦度)  ─→ 噪声类型 {white / pink / babble}
   │
   ├─[阶段1] SE 条件化降噪 (DeepFilterNet3)
   │         babble/white → atten=0 全力   pink → atten=6 温和(防过消除)
   │         ↓ denoised.wav
   │
   ├─[阶段2] enroll_infer  (--asr-backend vanilla 主线 / dicow fallback)
   │         ├─ DiariZen(wavlm-large) diarization → 各 speaker 时间段
   │         ├─ wespeaker 声纹(enrollment + 各 speaker,256d)→ 余弦匹配选 target_idx
   │         ├─ [vanilla 主线] 切 target timeline 段(含重叠区)拼接 → vanilla Whisper 转写
   │         └─ [dicow fallback] STNO mask + FDDT 条件化 → DiCoW 转(已证伪反作用)
   │
   ├─[阶段3] llm_reject (Qwen2.5-3B-Instruct)  ⚠️ 保底关(--no-llm), 双优 RTF+RR
   │         对 transcript 判 accept / reject(零样本,13 类拒识 schema + 自适应 CoT)
   │
   └─[阶段4] 融合 (sim_only 保底) + content_gate(可选, 默认关)
             rejected = (max_sim < sim_thr)                          # 保底 sim_only, thr=0.27(B 集统一)
             [content_gate] sim≥thr 且转写非有效家居指令 → 加拒     # hold-out val +2.5 分, BAODI_GATE=1 开
             ↓
result.json  +  timing.json  →  to_submission.py  →  官方 submission.json
```

**核心组件**(全部已开源、已跑通):

| 组件 | 实际用 | 备注 |
|---|---|---|
| 目标锁定 | **wespeaker-voceleleb-resnet34-LM**(256d,复用 `diar._embedding`) | 非 CAM++(T18 per-speaker 公平对照证伪,sim 0.191 < wespeaker 0.218); P1 oracle POC 进一步证声纹强化收益封闭 |
| 说话人分离 | **DiariZen**(diarizen-wavlm-large-s80-md) | 非理想态的 Personal VAD(未用) |
| **TS-ASR 转写(主线)** | **vanilla Whisper-large-v3-turbo**(809M,zero-training) | diar+声纹切 target timeline → vanilla 转;**CER 0.595 减半**(官方口径) |
| TS-ASR 转写(fallback) | **DiCoW**(BUT-FIT/DiCoW_v3_2,FDDT 条件化) | ⚠️ **已证伪反作用**(sim0.2-0.4 桶 CER 1.5-1.6、英文幻觉 18.7%), 仅答辩对比基线 |
| 语音增强 | **DeepFilterNet3**(条件化,8.7MB,纯 CPU) | 谱平坦度分桶,可部署 |
| 语义拒识 | **Qwen2.5-3B-Instruct**(6.17GB) | ⚠️ 保底**关**(`--no-llm`): decide_reject 是 AND, LLM 只减拒不加拒, 关 LLM 双优 RTF+RR |
| 融合决策 | **sim_only**(保底, thr=0.27) | 声纹 max_sim 单信号; llm_or_sim 实为 AND 已证伪"三路融合" |
| 内容二次拒 | **content_gate**(`text_utils.is_valid_command`) | 默认关; hold-out val +2.5 分, BAODI_GATE=1 开 |

### 反 cascaded 归因(⭐ 核心答辩弹药)

**全量真测 1362 条(官方口径累计池)坐实 DiCoW 条件化反作用**:

| 指标 | vanilla(主线) | DiCoW(fallback) | Δ |
|---|---|---|---|
| 转写 overall CER | **0.595** | 1.189 | −0.594(几乎减半) |
| correct(CER<0.5) | **48.8%** | 31.4% | +17.4pp |
| 英文幻觉率 | **0.6%** | 18.7% | −18.1pp(DiCoW 条件化主动造孽) |
| thr0.27 含拒 CER | **0.703** | 1.129 | −0.425 |
| sim[0.2,0.3) 桶 CER | **0.659** | **1.609** | −0.950(条件化最毒桶) |

**机制**:极重 babble 下 STNO 概率对 target 的判别失效(mel 退化 + 声纹 sim 低 → 凸组合权重错乱), FDDT 把错乱权重焊进 Whisper 输入, 比"不条件化"更糟。条件化是 DiCoW 核心卖点, 恰在题目最在意的极重 babble 区段反噬。改用 vanilla + target extraction(切 target timeline 段拼接 → vanilla 转), zero-training 即把 CER 减半。**契合出题方反 cascaded 审美 + 诚实归因 + 真数据背书**。详见 memory `h3-dicow-conditioning-backfire-vanilla`。

## 3. 各模块技术细节

### 3.1 目标锁定(wespeaker 声纹)

- **enrollment 声纹 + 各 speaker 声纹**统一复用 DiariZen 内部 `_embedding`(wespeaker backbone,256d),零额外模型加载。
- 抽 speaker 声纹时**优先 non-overlap 独占帧**(避开重叠污染),不足 0.3s 时 fallback 全 timeline;不足 1s 时 tile 补齐。
- **余弦匹配选 target**:`target_idx = argmax_i cos(enroll_emb, spk_emb_i)`,`max_sim` 作为"目标是否在场"的置信度。
- 可选 **enrollment 加噪增强**:enrollment emb = 干净 + 3 档加噪(10/5/0 dB)emb 均值 → 与带噪识别音频同分布,均 sim 提升 +59%。

### 3.2 TS-ASR 转写(vanilla 主线 + DiCoW fallback)

> ⭐ **2026-07-06 Phase 1 突破**:主线改为 vanilla Whisper + target extraction。DiCoW FDDT 条件化(下方)在极重 babble 下反作用, 降为 fallback/答辩对比基线。

**vanilla 主线(当前提交路径)**:
- diar+wespeaker 选 target(复用 `enroll_infer` 逻辑)→ 切 target timeline 段(含重叠区)拼接 → **vanilla Whisper-large-v3-turbo** 转写(去掉 stno_mask/FDDT 条件化)。
- 全量 1362 条 zero-training 真测:**转写 CER 0.595(官方口径)/ correct 48.8% / 英文幻觉 0.6%**。
- 提交归一 SSOT(`to_submission.py`):输出 text 经 `to_simplified`(zhconv 繁→简)+ `digit_postproc`(cn2an 阿拉伯→中文数字, 对齐 ref 口径)。

**DiCoW fallback(已证伪反作用, 仅答辩对比)**:
- **FDDT 仿射变换**将 `[silence / target / non-target / overlap]` 4 类 mask 注入 Whisper encoder **每一层**,对角约束 + `fddt_init=disparagement`(抑制式初始化) → 非目标帧被压到零输出。
- **STNO 验证(中英文均成立,T16)**:target 帧→正常转写;silence 帧→跳过;**non-target 帧→直接产出 0 字(内建拒识,非后处理)**。
- 基座 **Whisper-large-v3-turbo**(0.89G params,32 encoder + 4 decoder 层)。
- ⚠️ **反作用铁证(1362 条真测)**:sim[0.2,0.3) 桶 DiCoW CER **1.609** vs vanilla 0.659;英文幻觉 18.7% vs vanilla 0.6%。极重 babble 下 STNO 概率对 target 判别失效 → FDDT 把错乱权重焊进 Whisper 输入。详见 §2 反 cascaded 归因表。
- **已修 DiCoW `generation.py` language 死代码 bug**(T19):原代码 `language="zh"` 被静默忽略 → 退化音频上 `detect_language` 误检英文 → 90% 输出英文;补丁位置 `code/apply_dicow_langfix.py`,**HF 缓存清了需重打**。
- **STNO target 帧占比**(`stno_target_ratio`)曾拟作辅助校验信号,但 T19 验证其单独是**坏拒识信号**;拒识锚信号仍是声纹 `max_sim`。

### 3.3 SE 条件化(DeepFilterNet3)

- **谱平坦度**(spectral flatness)估每条识别音频的噪声类型:white(平坦度≈0.39)/ pink(≈0.11)/ babble(≈0.03),三类在 450 仿真集上**无重叠完全分离**。
- **条件化策略**(可部署,运行时纯谱分析无需 manifest):
  - babble / white → `atten_lim_db=0`(全力降噪)
  - pink → `atten_lim_db=6`(温和,防稳态噪声过消除反伤语音)
- 仿真集 SE 条件化 CER **2.82(相对 baseline 4.27 改善 −34%)**,且 diar-fail 数 33→0(pipeline 稳定性强信号)。

### 3.4 LLM 语义拒识(Qwen2.5-3B-Instruct)

- **零样本** few-shot prompt,按出题方 #1 论文(arXiv:2512.10257 Midea AI Research)13 类拒识 schema + 自适应 CoT 四步(实体识别 / 动作识别 / 参数合理性 / 结论)。
- **34 条零样本测试集**:F1=**0.878** / Precision=0.783 / **Recall=1.0**(fn=0,该拒全拒)/ Accuracy=0.853。vs 全 reject 基线 F1=0.69(+0.19)。
- 5 个误拒(fp)都是合法复杂指令(窗帘拉一半/净化器睡眠/热水器 45 度/灯暖色最低/十分钟后提醒关火),prompt 调优 + 声纹融合可纠正。
- 作用:**救回声纹误拒**(声纹在带噪下退化会误拒合法 target);T19 实测在 450 集 LLM 拒了 99.8%(因 DiCoW 转写垃圾被正确判非指令),故 LLM 在"转写良好"时才能发挥救回价值。

### 3.5 融合(llm_or_sim)

- 默认策略 `llm_or_sim`:`rejected = (llm_verdict ≠ "accept") AND (max_sim < sim_thr)`。
- 可选 `sim_only` / `llm_only`(见 `submit_infer.py --strategy`)。
- **设计意图**:LLM 偏严(语义不合理即拒),声纹偏宽;两者**双否决** = 都说不像 target 才拒 → LLM 救回声纹误拒、声纹救回 LLM 误拒(转写垃圾时 LLM 会误拒)。
- T19 target 缺席集(72 条)验证:`sim_only(t=0.2)` 真实拒识率 **100%**,`llm_or_sim` 融合亦 100%(max_sim 均 0.026,全部正确拒)。

## 5. 当前性能(诚实,datasetA 全量真测 1362 条,官方口径)

> ⭐ **2026-07-08 主办方 CER 口径坐实**(NFKC + lower + 去P* + 累计池 editdistance)。以下数字来自 `recompute_official_cer.json`(提交归一后), 详见 [`测试验证方案.md`](测试验证方案.md) §3。仿真 450 条旧数字已过时不再列。

### 转写 CER(vanilla 主线 vs DiCoW fallback)

| 后端 | 转写 overall CER | correct(CER<0.5) | near_perfect(CER<0.1) | 英文幻觉率 |
|---|---|---|---|---|
| **vanilla(主线)** | **0.595** | **48.8%** | 26.3% | **0.6%** |
| DiCoW(fallback) | 1.189 | 31.4% | 14.9% | 18.7% |

### thr 工作点 + sim 分桶(反 cascaded 铁证)

| thr(含拒累计池) | vanilla CER | dicow CER | sim 桶 | vanilla CER | dicow CER |
|---|---|---|---|---|---|
| 0.20 | 0.657 | 1.181 | [0.0,0.2)(死区, n=397) | 0.784 | 1.030 |
| **0.27(B 集统一)** | **0.703** | 1.129 | **[0.2,0.3)**(n=332) | **0.659** | **1.609** |
| 0.40(A 集分 thr 保底) | 0.825 | 0.912 | **[0.3,0.4)**(n=336) | **0.641** | **1.522** |
| — | — | — | [0.4,1.0)(轻 babble, n=286) | 0.280 | 0.638 |

### 拒识侧 + 效率

| 指标 | 结果 | 说明 |
|---|---|---|
| neg RR(thr0.27 统一) | **90.5%** | B 集单一 thr;thr0.4 则 RR 98.5%(A 集分 thr) |
| pos 误拒率(thr0.27) | ~50% | pos sim med 0.283 ≈ thr;pos/neg sim 重叠, 纯 thr 破不了 |
| content_gate(hold-out val) | ΔTS **+0.025(+2.5 分)** | 转写内容二次拒;10 seed 10/10 全正;默认关 |
| RTF | **0.2543** | 关 LLM + vanilla + thr0.27, pos 全量 3498s, **4060 实测(L20 待测)** |

### ⚠️ 性能瓶颈(诚实, 真测归因)
1. **死区是物理极限**:sim<0.2 死区(29%)经 P1 oracle POC 坐实是 babble 摧毁 mel(单 spk 控制组 n=18 CER 0.436 + miss 声纹反向 20/20), 非选择器工程缺陷 → 声纹强化(CAM++/US-PVAD)收益封闭已证伪。
2. **pos/neg sim 严重重叠**:pos sim med 0.283 / neg sim med 0.116, [0,0.4] 重叠 → 统一 thr0.27 是 trade-off(pos correct 31.8% / neg RR 90.5%), 分 thr oracle 损失 6.46 分是 B 集无 label 代价。
3. **100% 重叠单通道死区**:单麦克风无方向信息, diarization 退化为把主导声归到多 speaker, 靠 sim_thr 拒识兜底(最薄弱处)。
4. **CER 进一步破局**:vanilla 0.595 是组合主线天花板(死区物理极限封顶), 冲 CER 唯一未证伪方向 = babble 专用源分离(SepFormer 提 target 干净 mel, 高成本)。
