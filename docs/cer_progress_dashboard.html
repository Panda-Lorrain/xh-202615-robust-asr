诚实声明：

① 450 条为 mimo-tts 合成仿真集，非比赛真实测试集 A；绝对值不可外推到赛榜，仅反映工程链路相对水平与条件退化。

② 本次实测 overall CER 1.28、correct 14%：两次独立跑（本次 14.0% / T20 历史 15.1%）互证稳健，但 非系统可用——CER>1 即幻觉区，86% 的条转写不可用。

③ 强项：效率（RTF 0.058 纯推理 / 0.27 端到端，L20 会更优）+ 拒识机制（target 缺席集 100% 拒识、LLM 零样本 F1 0.878）。短板：带噪重叠中文转写（尤其 babble）。

④ 真瓶颈（T22 vanilla Whisper 三角定位，07-03 确证）：babble 英文幻觉/重复循环 100% 源自 DiCoW 的 FDDT/STNO 条件化在低覆盖率 STNO 下劣化，非 Whisper 基座问题（vanilla Whisper 同样本输出正确中文）。杠杆 = 提高 STNO target 覆盖率 / 全程 language forcing / babble 专用源分离。

⑤ LLM 拒识未在本跑（target 在场会因转写垃圾误拒 99.8%，掩盖转写水平）；拒识能力见 Hero KPI 与 RESULTS.md T18。

⑥ 待确认两件事卡真实进展：真实测试集 A + 通道数（决定空间分离 DSENet 能否用）。
