# TSE 复活验证：假设前提确认 + 同环境重训实验设计

> ⚠️ **2026-08-05 反瓶颈审计注释**：本文假设分支「若识别侧纹丝不动 → TSE 彻底封顶」中的"封顶"，按审计归类应理解为**合成域 + 代理损失前提的 `implementation-NO-GO`**。实际同环境 POC（`docs/TSE同环境POC结果_2026-08-01.md`）已证明真因是 enrollment-mixture 环境失配（非感知-识别鸿沟），同环境路线为 `conditional-GO`，真实/同环境域 TSE + 目标条件化联合训练仍 `direction-unresolved`。详见 `docs/反瓶颈审计与后续Agent作战令_2026-08-05.md`。

> **2026-08-01** | 验证假设：「07-29 TSE 失败真根因不是感知鸿沟，而是训练数据 enrollment-mixture 环境不一致（违反 A 集 ΔBG≈0 铁律）」
>
> 方法：第 1 步轻量本机纯分析（确认前提），第 2 步仅设计不跑训练。

---

## 0. 结论一句话（TL;DR）

**假设前提 decisively 成立**：07-29 TSE 训练数据的 enrollment 是干净 Aishell 切片（无噪、无 RIR），mixture 加噪 −5~5dB，**ΔBG 中位 +8~+11 dB**；而 A 集真实录制 ΔBG 中位 **−0.07 dB**（铁律）。两者差距 ~10 dB，是明确的训练域-评测域环境失配。**值得做最小 POC**（本机 4060 可跑），但修复数据是 TSE 复活的**必要非充分条件**——感知-识别鸿沟可能仍存在。

## 1. 第 1 步：假设前提确认（成立）

### 1.1 训练数据 enrollment 构造逻辑（代码铁证）

07-29 TSE 训练 triples 由 `code/experiments/tse_data_aug.py::synthesize_tse_triple` 生成。关键路径：

| 步骤 | mixture (recognition) 路径 | enrollment 路径 |
|---|---|---|
| 1. target 预处理 | 速度变换 + **RIR 卷积（50% 概率）** | — |
| 2. enrollment 切片 | — | `cut_enrollment(clean_enrollment_wav)` —— **从同说话人另一条干净 Aishell utterance 切 1.5–2.5s，无任何处理** |
| 3. enrollment 污染（可选） | — | `enroll_polluted = rng.random() < enroll_pollute_p`；balanced profile `enroll_pollute_p=0.15`，hard=0.30；**即便污染，SNR=+8~15dB（轻度）** |
| 4. 干扰人混合 | target + interferer @ SIR −5~5dB，interferer 也卷 RIR | — |
| 5. 加噪 | **加 white/pink/babble 噪声 @ SNR −5~5dB（重度）** | — |

**关键代码（`tse_data_aug.py:312-323`）**：
```python
# enrollment 必须来自同 speaker 的另一 utterance（干净 Aishell）
enroll = cut_enrollment(enrollment_wav, enroll_dur_sec, SR, rng)   # 无噪无 RIR
# enrollment 污染 (可选)，仅 15% 概率，且 SNR +8~15dB
enroll_polluted = rng.random() < enroll_pollute_p and noise_wav is not None
if enroll_polluted:
    enroll = pollute_enrollment(enroll, noise_wav, enroll_pollute_snr_db, rng, pollute_p=1.0)
```

**注释自证（`tse_data_aug.py:302-304`）**：「target 与 clean_target 共同一 RIR → SI-SDR 监督严格对齐; **enrollment 走独立路径 (cut_enrollment) 不卷积**。」

manifest 实测字段印证（`_tse_phase2_train_balanced/manifest.jsonl`）：
- `enrollment_src`: `E:/midea_datasets/data_aishell/wav/train/S0022/BAC009S0022W0431.wav`（干净 Aishell）
- `enroll_pollute`: 绝大多数 `false`（train_balanced 采样 40 条仅 1 条 polluted = 2%）
- `snr_db`（mixture 噪声）: −5~+5 dB
- → enrollment 几乎无底噪，mixture 重度加噪

### 1.2 ΔBG 量化验证（复用 `_a_reverse/deep_analysis.bg_noise_rms`）

对 enrollment vs mixture 算背景底噪 RMS（bottom 10% 能量帧中位 RMS → dB），ΔBG = bg_mix − bg_enr。A 集为真实同环境录制应 ΔBG≈0；合成 triples 若 enrollment 干净/mixture 加噪应 ΔBG≫0。

**脚本**：`code/runs/_a_reverse/cmp_bg_tse_vs_a.py`（复用 deep_analysis，未重写算法）。
**结果**（`code/runs/_a_reverse/cmp_bg_tse_vs_a.json`）：

| 数据集 | n | ΔBG 中位 (dB) | ΔBG [q25, q75] | ΔSNR 中位 (dB) | enroll 污染率 |
|---|---|---|---|---|---|
| **A 集（真实录制 pos）** | 40 | **−0.07** | [−6.18, +2.90] | **+0.52** | — |
| TSE phase2 val（07-29 评测 40） | 40 | **+8.28** | [+1.94, +17.57] | −7.56 | 42% |
| TSE phase2 val_balanced（200） | 40 | **+10.08** | [+4.70, +16.76] | −9.37 | 20% |
| TSE phase2 train_balanced（800） | 40 | **+10.96** | [+4.29, +19.16] | −8.62 | 2% |

**解读**：
- A 集 ΔBG=−0.07 dB（铁律坐实，与 `docs/A集合成方式逆向分析_2026-08-01.md` 一致），enrollment 与 mixture 同房间同底噪。
- 合成训练数据 ΔBG=+8~+11 dB，**enrollment 比 mixture 干净 ~10 dB**。ΔSNR 同步 −7.5~−9.4 dB（mixture 比 enrollment 噪 ~8dB）。
- train_balanced 的 enrollment 污染率仅 **2%**（balanced profile 名义 15%，但采样到的 40 条只命中 1 条）→ 绝大多数训练样本 enrollment 是纯干净 Aishell 切片。
- 差距 ~10 dB 是**明确的训练域-评测域环境失配**，直接违反 A 集 ΔBG≈0 铁律。

### 1.3 前提结论

**前提成立（CONFIRMED）**。07-29 TSE 训练数据的 enrollment（干净 Aishell 切片，无噪无 RIR）与 mixture（加噪 −5~5dB + RIR）环境严重不一致，模型学到的「enrollment 引导」是基于干净声纹特征，而 A 集推理时 enrollment 与 mixture 同环境含噪——**域 gap ~10 dB ΔBG**。这是 07-29 「声学翻正、识别不动」的一个**未被排除的混淆因子**，原归因「感知-识别鸿沟」可能在混淆因子未控情况下被高估。

**诚实保留**：前提成立 ≠ TSE 必复活。即便修复数据，感知-识别鸿沟（EoW 论文警告）可能仍存在。修复环境失配是**必要条件，是否充分需实验证伪**。

## 3. 第 2 步：同环境重训实验设计（仅设计，不跑训练）

### 3.1 数据改造方案（核心改动）

目标：让 enrollment 与 mixture 共享同一噪声环境 + 同一 RIR，使 ΔBG≈0 对齐 A 集铁律。

**改动点：`code/experiments/tse_data_aug.py::synthesize_tse_triple`**

当前（环境失配）：
```python
enroll = cut_enrollment(enrollment_wav, enroll_dur_sec, SR, rng)          # 干净切片
if enroll_polluted:                                                        # 15% 才污染
    enroll = pollute_enrollment(enroll, noise_wav, enroll_pollute_snr_db, ...)
# RIR 不卷 enrollment（注释明说）
```

改造（同环境，新增 `same_env_enrollment=True` 模式）：
```python
# 1. enrollment 卷与 target 同一 RIR（不再跳过）
if rir_applied:
    enroll = apply_rir(enroll, _rir_t)          # 用 target 的 RIR，非 interferer 的
# 2. enrollment 加与 mixture 同源、同底噪水平的噪声（ΔBG≈0）
#    取 mixture 使用的同一 noise 段，按 mixture 的 measured_snr_db 标定，
#    使 enrollment 背景底噪 ≈ mixture 背景底噪
noise_seg_for_enr = _fit_noise(noise_wav, len(enroll))
enroll_noise_level = scaled_noise_rms_used_in_mixture   # 复用 step5 标定后的噪声 RMS
enroll += noise_seg_for_enr * (enroll_noise_level / (_active_rms(noise_seg_for_enr)+1e-8))
```

要点：
- **同源噪声**：enrollment 用的噪声段与 mixture 同一 noise_wav（非独立采样），保证频谱形态一致。
- **同底噪水平**：enrollment 加噪的 RMS = mixture 中噪声的 RMS（不是按 SNR 重标定），保证 ΔBG≈0。
- **同 RIR**：enrollment 卷 target 的 RIR（同一房间位置），保证 ΔRT60≈0。
- 保留 `--same-env` 开关，可消融对比（同环境 vs 原 mismatch）。

### 3.2 实验设计

**训练配置**（复用 07-29，只改数据）：
- 模型：WeSep pBSRNN（commit 99eca54），`feature_dim=128, num_repeat=6, joint_training=False, use_spk_transform=False, spk_fuse_type=multiply`，CAM++ 512d embedding
- 损失：`−SI-SNR + 5×Qwen-mel-L1 + 1×wave-L1`（同 07-29 best config `finetune_balanced_qwenmel_w5_wave1`）
- batch=1（pBSRNN 变长强制），Adam lr=1e-3

**数据组**：
| 组 | 训练数据 | enrollment 环境 |
|---|---|---|
| **A（对照=07-29 原版）** | `_tse_phase2_train_balanced`（800，mismatch） | 干净 Aishell 切片（ΔBG +11dB） |
| **B（同环境新版）** | 重新生成 800 triples，`same_env_enrollment=True` | 同噪声+同 RIR（ΔBG≈0） |

**评测（必须复用 07-29 同一套，直接可比）**：
1. **声学侧**：`tse_wesep_train.py::evaluate` → SI-SNRi / Qwen-mel-L1 / wave-L1（验证分离仍翻正）
2. **识别侧**：`tse_wesep_infer.py` 导出 estimate → Qwen3-ASR 转写 → `tse_qwen_compare.py` 配对 CER + bootstrap CI（10000 samples）
3. **两套评测集**：
   - **合成 val（同环境新版 40）**：直接对比 07-29 的 `qwen_compare_val40.json`（raw_cer 1.2870 → enhanced Δ−0.0199）。注意 B 组 val 也必须是同环境数据（in-domain 公平）。
   - **A 集真实数据（终极测试）**：用 `a_eval_manifest_campp.jsonl` + A 集 enrollment，跑 TSE→Qwen，看 A 集 CER 是否动。**这才是假设的真正判据**（修复训练域 gap 后能否迁移到 A 集真实同环境）。

**GO / NO-GO 判据（同 07-29 门槛）**：
- ΔCER ≤ −0.05（enhanced vs raw）
- bootstrap 95% CI 上界 < 0
- 两套评测集均需过门槛（合成 val in-domain + A 集 transfer）

### 3.3 对照与消融

| 对比 | 回答的问题 |
|---|---|
| A vs B（合成 val） | 同环境数据是否让 in-domain CER 动？（排除感知鸿沟） |
| B 合成 val vs B A 集 | 同环境训练能否迁移到 A 集真实数据？（域 gap 是否唯一因子） |
| B 声学指标 vs B CER | 声学翻正后识别是否仍不动？（感知-识别鸿沟是否独立存在） |

## 4. 可行性 + 算力评估

### 4.1 本机 POC 可行性

- **GPU**：RTX 4060 Laptop 8.6 GB VRAM。07-29 训练 batch=1（pBSRNN 变长强制），短音频（~5-8s），pBSRNN 中型模型 → **8GB 应可跑 batch=1**（L20 48GB 远超所需，4060 是其 1/5.6 但 batch=1 门槛低）。
- **风险**：长音频（>10s）+ bidirectional LSTM 可能 OOM；可用 `--train-limit` + `--val-limit` 控制样本数与长度。
- **环境**：`code/.venv_tse`（torch 2.3.1+cu121）就绪，WeSep loader 已验证。

### 4.2 最小 POC 建议（本机先跑，省 L20 租金）

**目标**：快速看「同环境数据下识别侧是否动」（哪怕不过 −0.05 门槛，动 vs 不动是关键信号）。

| 项 | 最小 POC | 全量（租 L20） |
|---|---|---|
| 训练 triples | **40–80**（同环境，2 speaker） | 800（同环境） |
| epoch | **3–5** | 20 |
| 评测 val | 同环境 40 triples | 同环境 200 + A 集全量 |
| 预估耗时（4060） | ~1–2h | 不建议（8GB 多次 OOM 风险） |
| 预估耗时（L20） | — | ~6–8h（同 07-29） |
| 判据 | ΔCER 趋势（动不动） | ΔCER≤−0.05 + CI + A 集迁移 |

**POC 决策树**：
1. 本机 4060 跑 40 triples + 5 epoch（~1-2h）
2. 若识别侧 ΔCER 明显动（如 −0.03~−0.05 趋势）→ **租 L20 跑全量**，高概率复活
3. 若识别侧纹丝不动（ΔCER≈0，复刻 07-29 现象）→ **感知-识别鸿沟独立成立**，TSE 路径彻底封顶，不浪费 L20 算力

### 4.3 数据生成耗时

- 同环境 triples 生成与原版同量级（只是 enrollment 多加同源噪声 + RIR 卷积），800 triples 在本机 CPU ~10–20 分钟（librosa 加载 + sf 写出，07-29 已验证）。

## 5. 明确建议

1. **前提已坐实**（ΔBG +8~11dB vs A 集 −0.07dB，代码+数据双重铁证），**值得做同环境重训验证**。
2. **先本机 POC**（4060，40–80 triples + 5 epoch，~1–2h）：改 `synthesize_tse_triple` 加 `same_env_enrollment` 模式 → 重生成小份 triples → 复用 `tse_wesep_train/infer/qwen_compare` 全链路 → 看 ΔCER 动不动。
3. **POC 信号决定是否租 L20**：
   - ΔCER 动 → 租 L20 全量（800 triples + 20 epoch + A 集迁移评测），有望复活 TSE。
   - ΔCER 不动 → 感知-识别鸿沟被坐实为独立根因（非数据 gap），TSE 彻底封顶，省 L20 算力转 Phase-3 Sidecar。
4. **诚实提醒**：即便同环境重训，SI-SDR/mel 声学收益仍可能不传导到 CER（EoW 感知-识别鸿沟）。本 POC 的价值是**排除/坐实「数据 gap」这一混淆因子**——无论结果如何，都是对 07-29 归因的关键补刀。
