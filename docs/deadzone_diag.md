## 4. SepFormer oracle 死区天花板(60 条抽样, seed42)

> 产物: `code/runs/_deadzone_sepformer/summary.json` (n=60, 耗时 0.68min)

| 桶 | n | argmax 基线 | SepFormer+sim选路 | **SepFormer+oracle选路** | Δ(oracle-argmax) | oracle救回(correct) | sim选对oracle路 |
|---|---|---|---|---|---|---|---|
| 死区深 sim<0.2 | 30 | 0.3281 | 0.6541 | **0.3449** | +0.0168 | 21/30 (70.0%) | 17/30 |

| 死区整体 | 60 | 0.3277 | 0.5283 | **0.289** | -0.0387 | 44/60 (73.3%) | 40/60 |

**核心发现**:
- **死区整体 SepFormer+oracle mean CER 0.289 vs argmax 0.328 (Δ-0.039)** — oracle 略胜, 73.3% 死区样本 oracle 救回(CER<0.5).
- **死区浅 [0.2,0.4) oracle 显著胜**(Δ-0.094, 23/30 救回) → 这部分根本不是地板, 是机器 argmax 选路失败.
- **死区深 sim<0.2 oracle 持平 argmax**(Δ+0.017, 21/30 救回) → 仍有 70% 可救子集, 仅 9/30 是分离后两路都拿不到的真地板候选.
- **sim 选路失效**: 死区深 SepFormer+sim 选路 mean CER 0.654 远坏于 oracle 0.345 (Δ+0.326 vs argmax) — 分离拎出了干净 target, 只是 sim 在死区太低选错路; 改进 target selector 是关键.

**对老结论的修正**:
- 老 `exp_sepformer_qwen.json` (n=40 sim<0.2): sep 0.687 vs argmax 0.410, oracle 0.413 → **当时判 GO=否**.
- 本次重测 (n=60, 30+30 分桶): **死区浅 [0.2,0.4) oracle 显著有效(Δ-0.094)**, 死区深 sim<0.2 oracle 持平但 70% 仍可救. 老结论的"死区物理地板"被推翻.

> ⚠️ oracle 是"两路取最优"天花板, **部署不能 oracle**. 实际收益取决于 target selector: 当前 sim 选路在死区失效(死区 sim 全部 <0.4), 需要非声纹的 selector (如 LLM 选家居指令段 / Whisper-Sidecar embedding). 见 memory `non-voiceprint-target-selection`.

| M2 机器选错 target | 1.2% (13, 仅 sim<0.2 60 条统计) | argmax 选错 spk, oracle 能拿 CER=0 — **明确可救** |

**SepFormer oracle 死区天花板(60 条抽样)**:
- 死区整体 oracle_mean **0.289** vs argmax 0.328(Δ-0.039) — 73.3% 救回
- 死区浅 [0.2,0.4) oracle 显著有效(Δ-0.094) — 这部分不是地板
- 死区深 sim<0.2 oracle 持平 argmax(Δ+0.017), 但仍有 70% 救回 — 真地板仅 ~30%

**死区天花板的真相**:
1. 死区 50.7% 机器已经成功(CER<0.2), 之前笼统说"死区是地板"完全错了;
2. 另外 18.9% 是机器失败但人耳**可能**可辨(M2/M3/M4/M5), 是改进空间;
3. 真正的"人耳不可辨"地板候选只占 ~30%(M1), 还要等用户听 recognition 验证 —
   其中的人耳可辨部分(机器转崩)其实是"人耳可辨机器做不到", 是训练/微调能攻的方向;
4. SepFormer oracle 数据印证: 即便死区深 sim<0.2, 分离后两路 oracle 仍能拿 21/30 救回 → 真地板 <30%.

**改进方向(按 ROI)**:
- 🥇 非声纹 target selector(sim 在死区全部失效, SepFormer 拎出干净 target 但 sim 选错路) → 见 memory `non-voiceprint-target-selection`
- 🥈 M4 转写接近可纠正(178 条): beam search / initial_prompt / 规则同音字
- 🥉 M2 选错 target(明确可救): 改进 enroll 声纹(CAM++ 失败, 试 Whisper-Sidecar embedding 空间分离)
- ⏸️ M1 真地板子集(待听验证后定向): 人耳可辨机器做不到的, 才是训练/微调的靶子
