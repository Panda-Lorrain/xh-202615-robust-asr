## 4. baseline TER（A 集 20 条）vs 我们 CER — 域 gap 量化（核心交付）

### 实验设置
- **baseline**：REAL-TSE 官方 `spk_emb_100`（BSRNN separator + ECAPA_TDNN_GLOB_c512 speaker encoder，Libri2Mix-100 训，非因果，speaker-embedding 融合）
- **推理**：`wesep.load_model_local` → `extract_speech(mixture, enroll)` → 提取 wav → sherpa-onnx Zipformer-ZH 转写
- **A 集样本**：`datasetA/pos.jsonl` 随机抽 20 条（seed=2026），单通道 16kHz mono，enrollment ~1.8s
- **CER 口径**：① 逐条 mean（jiwer）；② **累计池**（CERMetric: total_errors/total_chars，与 qwen 0.3436 严格对齐）；③ TER（REAL-TSE zh normalizer: whisper-normalizer basic + opencc t2s，对比用）
- **环境**：CPU（torch 2.13 CPU + torchaudio 2.11），venv_realt
- 脚本：`code/runs/_realt_baseline/run_baseline_A.py`，结果：`code/runs/_realt_baseline/A_spk_emb_100_n20/results.json`

### 核心数字

| 指标 | baseline (spk_emb_100, Libri2Mix 训) | 我们 qwen 主线 | 倍数 |
|---|---|---|---|
| **CER 累计池（与 qwen 严格对齐）** | **0.8060** | transcribe **0.3436** | baseline **2.35x** 差 |
| CER 累计池 vs 含拒 | 0.8060 | 含拒 thr0.27 **0.5934** | baseline **1.36x** 差 |
| CER 逐条 mean | 0.9193 | - | - |
| TER（REAL-TSE zh normalizer） | 0.8060 | - | - |
| median CER | 0.875 | - | - |
| correct rate (CER<0.5) | 9/20 = **45%** | - | - |
| near-perfect (CER<0.1) | 4/20 = **20%** | - | - |
| mean TSE time / 条 | 2.4s（CPU） | - | - |
| mean ASR time / 条 | 0.06s | - | - |

### 样本表现（20 条，两极化分布）
- **完美（CER=0）4 条**：id=243「烹饪模式」、id=2866「播放小脚丫妈妈读绘本」、id=2497「吃什么有利于儿童」、id=2893「开一下空调」
- **部分对（0<CER<0.5）5 条**：id=2093「空调十六度→空调日六米」CER 0.4、id=2908「儿童不能吃什么→不能生什么」CER 0.143 等
- **完全错（CER≥1）11 条（55%）**：id=2290「关闭节能模式→彻底和解」、id=2808「风速五十→越南邮政银行被打出个屁股」CER 3.0、id=2539「风往右吹→十四点二十五和十八比二十五」CER 3.25（Zipformer 在烂提取音频上幻觉严重，CER>1 插入多）

### 域 gap 机制归因
1. **合成→真实声学域 gap**：baseline 在合成 Libri2Mix-100 上 SI-SDR 12-16dB（README §4 表），到真实 A 集 CER 0.806——separator 在真实重叠/噪声下分离质量崩塌（A 集是真实家庭录制，见 memory `a-set-is-real-recorded`，SNR 中位 16.8dB 但 sim 中位 0.21 target 不占主导）。
2. **感知-识别鸿沟再印证**：即便 separator 部分有效，提取音频经 Zipformer 转写后 CER 仍 0.806——印证 memory `tse-phase2-full-nogo` 的"感知鸿沟"（声学收益不传到 ASR CER），且 baseline 用的是 Zipformer（比 Qwen3 鲁棒）仍崩。
3. **enrollment 短失配**：A 集 enrollment ~1.8s（A 集实测，memory `datasetA-spec`），ECAPA-TDNN 在 1.8s 短 enrollment 上 speaker embedding 不稳，导致选错 target → 完全错（如 id=2808 选了干扰人）。
4. **训练数据域失配**：Libri2Mix 是英文朗读合成重叠，A 集是中文家居真实对话——语言+场景+采集三重失配。

### 关键洞察（与项目历史串联）
- baseline CER 0.806 ≪ 我们 qwen 0.3436，**说明 zero-training 的 target-timeline 切割 + Qwen3-ASR 路线，反而比合成训 TSE baseline 强 2.35 倍**——这是 memory `h3-dicow-conditioning-backfire-vanilla` 路线（vanilla Whisper + 声纹切 target）的工程价值铁证。
- 支撑 memory `synth-data-lora-domain-gap-nogo` + `tse-phase2-full-nogo` + `tse-poc-weak-go-overturns-perception-gap` 的链：**合成训到顶（baseline 0.806 是合成训天花板证据），真人真实录（REAL-PS4 同环境或自录）是唯一突破路径**。

## 6. 下一步建议

### 6.1 立即可做（低风险，高 ROI）
1. **全量 baseline 在 A 集 1364 条**：CPU 2.4s/条 × 1364 ≈ 55 分钟。可装 GPU 加速到 ~5 分钟。目的：拿全量 CER 数字（20 条样本方差大），确认 0.806 是稳定数字。脚本已就绪（改 `N_SAMPLES` 或全量）。
2. **测另外 3 个 baseline 模型**（spk_emb_causal_100 / tfmap_context_100 / tfmap_context_causal_100）：README EVAL1 表显示 tfmap_context 略优（TER 0.801 vs spk_emb 0.816）。看是否有更适配 A 集的。
3. **REAL-PS4 续传**：`git clone https://huggingface.co/datasets/TaurenMountain/REAL-PS4`（git-lfs），或子集 `allow_patterns=['AISHELL-4/*']` 先下 549MB 验证训练可用性。

### 6.2 战略方向（基于 baseline 域 gap 证据）
1. **REAL-PS4 训 pBSRNN 替 Aishell 合成**：REAL-PS4 是真实会议录音（AISHELL-4/AliMeeting 等衍生物），域更接近 A 集（真实家庭）。用 REAL-PS4 训 TSE 替代我们之前的 Aishell+MUSAN 合成训（phase2 NO-GO 的根因）。预期：CER 从 baseline 0.806 显著下降，可能逼近或超过 qwen 0.3436（因为 separator 端真训 + Qwen3 ASR 端）。
2. **PS4 联合训范式**：PS4 模型用了 proxy-supervised 联合训（separator+ECAPA+Whisper），论文 arXiv:2607.08111。直接用 PS4 checkpoint 在 A 集做 zero-shot 推理对照（Apache-2.0 可商用），可能比 spk_emb_100 baseline 强。
3. **REAL-T 注册获取**：若决定参赛 REAL-TSE Challenge，注册拿 dev set 做对照（真实对话场景，比 REAL-PS4 会议更接近家居对话）。

### 6.3 不建议
- 不要直接拿 baseline 0.806 当"提交线"——它是合成训在 A 集的下限证据，不是我们的方案。我们提交线仍是 qwen 0.3436（transcribe）/0.5934（含拒）。
- 不要因 baseline CER 高就否定 TSE——baseline 是合成训，真训（REAL-PS4 或自录）未试。memory `tse-poc-weak-go-overturns-perception-gap` 已示 same_env POC 止跌（Δ−0.0046），真人真实录可能突破。
