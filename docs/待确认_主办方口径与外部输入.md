## ✅ 已坐实（CER 口径 · 2026-07-08 主办方脚本 + 问题一正式确认）

**这是本阶段最大的口径风险解除（原 caliber-A 核心）。**

### 主办方问题一正式答复（2026-07-08）
**CER = (S + I + D) / N**，标准字符级 Levenshtein 编辑距离公式，参考 `editdistance` 库。
- S=替换 / I=插入 / D=删除 / N=GT 参考文本总字符数
- = 编辑距离 ÷ GT 字符数；中文按字符（区别于英文 WER 按词）
- 举例：GT「我爱中国」(4字) / Hyp「我很国」→ 编辑距离 2（插"很"+删"中"）→ CER=2/4=0.5

### 主办方参考脚本（2026-07-08 到手，全坐实）
`normalize_text`（unicodedata.NFKC + lower + strip + **去所有 Unicode P* 标点和空白**）+ `CERMetric`（**累计池** total_errors/total_chars，editdistance 库；空 target errors==0→0 else→1.0；拒识条 pred 空 → errors=len(ref) → CER=1.0 天然）。

**预处理口径四点**：(a) **不繁简归一** (b) **不数字归一**（ref「二十六」非「26」）(c) **标点不计入**（P* 过滤）(d) NFKC 全角→半角。

### 我们的实现（已对齐，4-agent 对抗验证）
`code/eval_metrics.py` 照抄 `normalize_text`/`CERMetric`/`cer_pool`/`cer_official`，逐行等价、12 边界 Δ=0.00e+00。旧 `cer()`(jiwer 逐条平均) 保留向后兼容，overall 两口径差<0.01。
- **提交侧归一 SSOT**：`to_submission.py:50` `digit_postproc(to_simplified(text))` —— 提交侧做繁简+数字归一，正好对齐 ref（全简体+全中文数字+无标点，各 0/1364）。
- **digit_postproc 收益 -0.033 坐实**；to_simplified 修 vanilla 243/1364 繁体条。

### 重算数字（recompute_official_cer.py，1362 条提交归一后，累计池）

## ✅ 已由 FAQ 确认（2026-07-06 公布 + 2026-07-08 问题二/三补确认）

### Q1 ✅ pos 被拒时 CER 怎么算？+ 是否允许拒？
**答**：rejected pos → CER=1.0（标准字符级 Levenshtein，hyp="" 时 D=N, S=I=0, CER=N/N=1.0）。**无额外惩罚（×1.5/×2 等）**。与"整段全错"扣分力度完全一致。
- 负样本不计 CER，只计 RR；正样本只计 CER，不计 RR。
- **2026-07-08 主办方补确认（规则层）**：**pos 隐含允许被拒**（无"pos 必须转写不许拒"规则）→ thr=0.27 可用，**caliber-A 彻底解除**。
- `eval_datasetA.py` / `eval_full_test.py` 已正确实现。

### Q2 ✅ CER/RR → 分数 排名公式
**答**：**排名制**，网站按公式排序：**`TotalScore = w1*(1−CER) + w2*RR`**（2026-07-08 主办方公布）。
- 线性、**(1−CER)** 非 correct_rate、**无额外惩罚项**、per-sample 不封顶（CER 可>1，1−CER 可为负）。
- **w1/w2 具体值未明示**，最可能 w1=w2=0.4（与 CER40%/RR40% 一致）→ **此时 thr=0.27 已是最优**（T27 目标函数即 (1−CER)×40+RR×40，与公布公式等价），无需重扫；仅当 w1≠w2（RR-heavy）才需上移 0.35–0.40。
- 效率 20%：公式未含，疑为决赛/tiebreaker 项（待确认）。

### Q3 🟡 neg 拒识率是句准还是 char-weighted？
**FAQ 未明确**。自测：7 条漏拒含长新闻 23 字，char-weighted RR 与句准 98.52% 差 ≤0.1pp（漏字仅占全集等效字数 1.1%），风险极低。**可不问**。

### Q4 ✅ 效率分（20% = 时间 10% + 内存 10%）+ batch 口径
- 统一 GPU 环境：**L20-46G**
- "其他算力和内存暂不做额外限制"
- **batch_size（2026-07-08 确认）**：默认 1；**大 batch 结果一致也允许，但 RTF（效率分）按 batch=1 测** → 大 batch 不加分 → **不做 batch 改造**，效率优化锁定 batch=1 路线（关 LLM RTF 0.24 + 模型量化/蒸馏）。
