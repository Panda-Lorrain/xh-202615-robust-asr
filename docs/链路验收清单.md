# 链路验收清单（逐工位产出 + 验收方法）

> 用法: 拿一条样本(如 cmd_2637), 从工位 0 走到工位 8, 每个工位听/看产出, 定位故障在哪一步。
> 代码主入口 enroll_infer.py(阶段2核心) + submit_infer.py(编排)。

样本路径模板:
- enrollment: `E:/midea_target_asr/datasetA/pos/kws_{N}.wav`
- recognition: `E:/midea_target_asr/datasetA/pos/cmd_{N}.wav`
- ref(正确答案): pos_pairs_datasetA.json 里 id=N 的 ref 字段

---

## 工位 0 · 输入音频
- **产出**: 两路 wav(enrollment + recognition), 16k mono
- **怎么验**: 听 enrollment 是否"干净 target 参考"; 听 recognition 的场景(单人/双人重叠/噪音)
- **典型故障**: enrollment 被污染(含多人)。cmd_2637 的 enrollment 里 A 小声说"小美小美"+B 一直在说 → enroll_emb 从源头就不纯。
- **代码**: 无(题目给定)

## 工位 1 · enrollment 声纹
- **处理**: wespeaker(enrollment) → enroll_emb(192 维向量)
- **产出**: enroll_emb(内存向量, 不存盘; 开 --enroll-augment 则是干净+多档加噪 emb 均值)
- **怎么验**: ① enrollment 里跑 diar, 看分几人(>1=污染); ② 听 enrollment 各子段, 判 enroll_emb 被谁主导
- **典型故障**: enrollment 污染 → enroll_emb 混入非 target。**但 cmd_2637 验证: 即便拆开 enroll 各段 emb, argmax 仍选 spk0 → 污染存在但非选 target 主因。**
- **代码**: enroll_infer.py:203-225 (get_enroll_emb)

## 工位 2 · diar 说话人日志 ★(主瓶颈所在)
- **处理**: DiariZen(recognition) → 每个 speaker 的时间段
- **产出**: speakers 列表(如 [0,1]) + per_spk timeline(每 speaker 何时说话); 可存各 speaker 完整段 wav
- **怎么验**: ① 分出几个人(单人样本应 1 人); ② **听各 speaker 段是否纯净(只一人)** —— cmd_2637 的 spk0/spk1 都含两人=欠分; ③ 重叠率 = (各 spk 段总长 − 音频长)/音频长, >10% 即重叠场景
- **典型故障**: 双人重叠欠分(spk 段混人, cmd_2637); 漏人; 过分(一人拆两)
- **代码**: enroll_infer.py:237-245

## 工位 3 · 各 speaker 声纹抽取
- **处理**: 对每 speaker, 从 non-overlap 独占帧抽 wespeaker emb; 不足 fallback 全 timeline; 再不足 np.tile 到 1s
- **产出**: spk_emb_0, spk_emb_1 ...(内存向量)
- **怎么验**: ① 每段独占帧多长(短→emb 不稳); ② 是否 fallback 全 timeline(引入重叠污染); ③ 是否 np.tile(tile 破坏周期性, emb 存疑)
- **典型故障**: 独占帧太短 → fallback 全 timeline → spk_emb 混入别人 → sim 不准
- **代码**: enroll_infer.py:252-262 (collect_clean_audio + get_emb), collect_clean_audio:73

## 工位 4 · 选 target(argmax 余弦)
- **处理**: cos(enroll_emb, spk_emb_i), argmax → target_idx, max_sim
- **产出**: sims 字典(各 spk 余弦) + target_idx + max_sim
- **怎么验**: ① sim gap(最高−次高), gap 小→选择不确定; ② **听各 spk 段判 argmax 选的是不是真 target** —— cmd_2637 选 spk0(含 B 多, sim 0.647), 但 spk1(含 A 更完整) sim 只 0.388 被淘汰
- **典型故障**: argmax 选错(target 被 B 主导的 enroll_emb 带偏, 或 spk_emb 脏致 sim 不可比)
- **代码**: enroll_infer.py:265-267

## 工位 5 · 切 target timeline
- **处理**: cut_target_timeline(audio, per_spk[target_idx]) → 拼接 target 各时间段(**含重叠区**)
- **产出**: target_audio(一维数组) → 切片 wav(`target_slices_full/cmd_N.wav`)
- **怎么验**: ① 切片时长(vs 原 recognition); ② **听切片是否混人** —— cmd_2637 切片含 A+B 两人; ③ 段间拼接断点
- **典型故障**: 重叠区混入干扰人(target 段和非 target 段时间重叠时, 切出来是混合音); 拼接断点致 ASR 跨段幻觉
- **代码**: enroll_infer.py:317(qwen)/300(vanilla), cut_target_timeline 在 text_utils.py:58

## 工位 6 · ASR 转写
- **处理**: qwen/vanilla/dicow(target_audio) → transcript
- **产出**: transcript(文本)
- **怎么验**: ① transcript vs ref 的 CER; ② **transcript 内容是不是切片里最响的人** —— cmd_2637 qwen 转"就已经进行过一轮交"(B 的话), 因 B 在切片里更响, **ASR 没错, 忠实转了切片**
- **典型故障**: 切片混人 → ASR 转 louder 的非 target(这步的错是上游传下来的, 不是 ASR 本身)
- **代码**: enroll_infer.py:315-323(qwen,调 qwen_asr_backend.py)/309-313(vanilla)

## 工位 7 · 后处理
- **处理**: to_simplified(繁简) → digit_postproc(阿拉伯→中文数字) → brand_homophone_fix(美的功能名同音)
- **产出**: 最终 text
- **怎么验**: 对比工位6 transcript, 看三步归一是否正确(数字/品牌名/繁简)
- **典型故障**: 后处理顺序敏感(未测); 数字/品牌同音漏修
- **代码**: enroll_infer.py:378-380

## 工位 8 · 拒识决策
- **处理**: max_sim ∧ content_gate(开) ∧ LLM(关) → rejected; pos 不该拒, neg 该拒
- **产出**: rejected 布尔 + 最终输出 text
- **怎么验**: ① pos 被 wrong-reject 没; ② neg 漏拒没(转出了非 target 的话); ③ 拒识依据(sim/content_gate)是否合理
- **典型故障**: TRAP(非 target 真说家居指令, 文本层拒不掉)
- **代码**: submit_infer.py decide_reject(67) + enroll_infer.py:279/394

---

## 故障归因速查(从工位反推)
| 现象 | 先查哪个工位 |
|---|---|
| 切片混人 / 转出别人的话 | 工位 2(diar 欠分) + 工位 5(切重叠区) |
| 选错 target(听各 spk 段判) | 工位 4 + 工位 1(enroll 污染) + 工位 3(spk_emb 脏) |
| 切片对但转写崩 | 工位 6(ASR), 排查 mel/小声 |
| 数字/品牌名错 | 工位 7 |
| neg 漏拒 / pos 误拒 | 工位 8 |
