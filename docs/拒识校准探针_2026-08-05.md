# 非内容拒识校准探针（2026-08-05）

## 结论

本轮完成了一个**只在 Dataset-A 外**运行的非内容拒识校准探针：使用 Qwen decoder token 置信度/熵、音频质量和现有声纹/活动特征，在 speaker-disjoint 的 AISHELL-1 dev 合成交叠集上训练、选阈值、冻结后测试。

裁决：

- **这套当前实现：`implementation-NO-GO`**。val 的单条救回没有泛化到 test，不能接入提交线。
- **非内容拒识校准方向：`direction-unresolved`**。本轮数据是外部 AISHELL 合成重叠，不是真实家居录音；它只能否掉当前探针，不能封死真实域校准。
- **Dataset-A 未用于训练、选阈值或特征选择**；本轮也没有改 `submit_infer.py` 默认行为。

## 数据与实验边界

- 数据：`E:\midea_datasets\data_aishell` 的 AISHELL-1 dev，构造 400 条 speaker-disjoint overlap probe。
- 划分：train 24 speakers / val 8 speakers / test 8 speakers，各 200 条 target-present、200 条 target-absent。
- 正样本：enrollment 目标说话人出现在 recognition 混音中；负样本：目标说话人不在 recognition 混音中。
- 基线：`max_sim >= 0.27` 接受，否则拒识。
- 候选是 rescue-only：基线已经接受的样本不改，只允许对基线拒识样本用校准器重新接受。
- 特征不读 transcript、关键词或内容 gate；比较两组：
  1. `base`：`max_sim`、说话人数、STNO/target activity 比例；
  2. `base_plus_decoder_audio`：再加入 Qwen token log-prob/top1/entropy/长度/EOS，以及 RMS、峰值、削波率、过零率、时长。
- Qwen 推理和候选决策使用同一份 `infer.json`，因此 raw/candidate 只改变拒识决策，不重复跑 ASR。
