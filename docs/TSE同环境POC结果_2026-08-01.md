## 0. 结论（TL;DR）

- **实现 PASS**：same_env 合成 ΔBG 中位 **−2.54dB**（接近 A 集 −0.46 / 铁律 −0.07），对照 mismatch **+10.01dB**。

- **A 集识别 CER（n=120，同进程 Qwen3-ASR，10000× bootstrap CI）**：

  - ✅ same_env **显著优于 mismatch**（Δ−0.0359，CI 全负，17b/6w）→ 域匹配在识别侧产生**统计显著**收益。
  - ✅ base0729（07-29 最佳 mismatch 模型）在 A 集**显著恶化** CER（CI 下界触 0）→ 复现 07-29 freeze，证据指向**域失配是主动恶化源**（separator 输出域内 artifact 干扰 Qwen）。

## 1. same_env_enrollment 实现 + 冒烟测 ΔBG

**改动**：`code/experiments/tse_data_aug.py::synthesize_tse_triple` 新增 `same_env_enrollment: bool`（+ `build_tse_pairs` 透传 + CLI `--same-env`）。启用时（step 4b）：
1. enrollment（从干净 `enrollment_wav` 截取，未经 step1a RIR）卷 target 同一条 `_rir_t`（**首次卷积，无双重**）。
2. 取 mixture 中实际噪声波形 `scaled_noise` 的随机连续段，**绝对水平直接复用**加到 enrollment（同源不同段，模拟真实录制 enroll/mix 同房间不同时间窗）。
3. peak-norm 用 recognition+enrollment 联合峰值 → ΔBG 精确不偏。
4. 跳过旧 `enroll_pollute`（同环境噪声已取代轻度 SNR+8~15dB 污染）。

**实现核对**（本次）：enrollment 来自 `enrollment_wav`（原始干净，非 RIR 后 target）→ step4b 首次卷 _rir_t，无双重 RIR bug；ΔBG 冒烟 + 评测集实测均 PASS。

**ΔBG 实测**（`cmp_bg_tse_vs_a.py` 同套 `bg_noise_rms` 算法）：

| 评测集 | n | ΔBG 中位 (dB) | [q25, q75] | 说明 |
|---|---|---|---|---|
| A 集评测子集（真实录制） | 120 | **−0.46** | [−4.94, +3.48] | 铁律 ΔBG≈0 |
| same_env val（合成同环境） | 40 | **−2.54** | [−7.60, −0.17] | 接近 A 集 ✓ |
| mismatch val（07-29 balanced） | 40 | **+10.01** | [+3.78, +24.30] | 失配 ✗ |

（阶段1冒烟 8 triples ΔBG −0.57，|ΔBG|<1dB 判据 PASS。）参考：A 集铁律 −0.07；07-29 mismatch train +10.96。

## 2. 配对训练设计（关键：修前 agent 架构 bug）

**前 agent 的坑（本次发现并修正）**：

- 只跑 3 epoch（epoch3 还发散，val_obj 8.31→12.19）→ SI-SNRi −0.11，nondegraded 40%（欠拟合，没法公平比）。
- 产物 `code/runs/tse_wesep_phase2/same_env_poc_e5/`（262MB checkpoint）**已废弃**（架构不对，不进评测）。

**本次配对设计**（唯一变量 = same_env，其余完全一致）：

- 训练：5 epoch，batch=1，lr=1e-3，seed=20260729，**from scratch**
- **mismatch 控制组**：从已有 `_tse_phase2_train_balanced`（07-29 原始 balanced profile，same_env=False）按相同 16 speaker 抽 80（`runs/_tse_same_env_poc/mismatch_train/`）。

## 4. GO / NO-GO 判定：**弱 GO（方向性成立）**

**支持假设**：
- same_env 显著优于 mismatch（CI 全负）+ base0729/mismatch 在 A 集显著/趋势恶化 → **域失配确为 07-29 freeze 的一个主动恶化源**。修域后 separator 不再"帮倒忙"。
- 定性 same_env 救回目标句，机制可见。

**保留（诚实）**：
- same_env 未显著优于 raw（Δ−0.0046，CI 跨 0）。POC 规模下 same_env 价值=「止跌」而非「拉动」。要拿到绝对 CER 下降，推测需：①数据规模 80→800+；②更多 epoch；③可能仍需 Phase-3 ASR-loss 反传把声学收益压到识别目标。

**规模限制声明**：
- POC：80 train triples（vs 07-29 balanced 800）、5 epoch from scratch（vs 07-29 finetune）、120 A 集子集。
- mismatch 控制组与 same_env 处理组的 target/interferer/noise 抽样**不同源**（between-groups，非 within-pair），但 speaker 集 + profile + 架构 + 配方一致。
- same_env val 与 mismatch val 是不同合成集（ΔBG 不同），val CER 不可直接比；A 集是唯一同条件对比。
- 120 条子集 bootstrap CI 仍宽（±0.03~0.04），全量（1364 条）CI 会收窄。

## 5. 若全量（L20）计划

1. 数据：same_env 800 train triples（复用 `tse_data_aug.py --same-env`，balanced profile，speaker-disjoint）+ 200 val。
2. 训练：fd=64/nr=3/mel5+wave1，从 07-29 base checkpoint finetune（对齐 finetune_balanced 配方），20 epoch，L20 ~8h。
3. 评测：A 集全量 1364 pos，同进程 Qwen 配对，bootstrap CI（全量 CI 大幅收窄）。
4. **GO 判据（全量）**：same_env enhanced CER vs raw Δ≤−0.03 且 CI 上界<0 → 集成主线；否则 TSE 路径封顶。
5. 若 same_env 全量仍仅"止跌"（Δ≈0 vs raw），则域失配只是「不帮倒忙」，真正拉 CER 仍需 Phase-3（ASR loss 反传：冻结 Qwen encoder 前 1/3 层 + Sidecar bias + target activity head，参数<5%）。
