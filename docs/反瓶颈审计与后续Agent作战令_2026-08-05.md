# 反瓶颈审计与后续 Agent 作战令（2026-08-05）

> 这份文档的目的不是把失败实验擦掉，而是防止“某个实现 NO-GO”被后续 Agent 误读成“整个方向没有空间”。所有旧结论继续保留；从本文件开始，结论必须标明适用条件。

## 一、先给结论

项目当前不是“什么都做不了”，而是：

> **现有提交配方已经进入收口期；研究空间没有封顶。**

目前真正被封住的是“在 Dataset-A 上不训练、用合成失配数据训练、再接当前 Qwen/声纹拒识栈”的若干低成本路径。尚未被封住的是同环境/真实录音数据、目标说话人条件化联合训练，以及围绕误拒与漏拒的非内容拒识建模。

这一区分必须成为后续 Agent 的默认前提。

## 二、已经被证实的事实

### 1. 当前提交线的损失漏斗，不等于 ASR 本体已经到顶

- 07-30 全量权威提交线：累计池 CER `0.6201`、RR `94.73%`；不拒识的 transcribe pool CER 是 `0.3442`。
- 因此，当前分数的巨大损失来自“目标句被拒后按 CER=1 计罚”，不只是 Qwen 把声音听错。
- 这条链路的核心困难是：pos 里的低相似度目标句要放行，neg 里低相似度的干扰人家居指令又必须拒掉。只看“像不像家居指令”无法解决身份问题。

### 2. 已证伪的是具体规则，不是所有拒识建模

- `n_spk=1 强制不拒` 已被 neg 全量验证推翻：neg 中 `n_spk=1` 为 `333/474=70.25%`，正是题目设计的干扰人独白 trap，强制接受会把 RR 打到 `31.86%`。
- 内容 rescue 已被 neg 全量验证推翻：干扰人也会说完整家居指令，内容信号在 pos/neg 上对称失效。
- 这两条结论的正确表述是“这两个信号/规则 NO-GO”，不是“拒识没有提升空间”。decoder 置信度、音频质量、目标条件化分数、双路一致性、用非 A 数据训练的拒识校准器仍未完成验证。

### 3. 07-29 TSE NO-GO 有重要的训练域前提

A 集逆向分析显示它是真实录制：enrollment 与 mixture 的背景差 `ΔBG` 中位约 `−0.07 dB`。07-29 TSE 训练 triples 的 `ΔBG` 中位约 `+8~+11 dB`，即 enrollment 几乎干净而 mixture 是重噪声，存在约 10 dB 环境失配。

因此，07-29 的严谨结论应写成：

> **mismatch 合成数据上的 pBSRNN/代理损失路线没有把声学收益传给 A 集 CER。**

不能写成：

> **所有 TSE、所有真实数据训练、所有目标条件化 ASR 都已经失败。**

### 4. 8 月 1 日同环境 POC 已经改变证据等级

同环境 POC 把 enrollment 与 mixture 对齐到同一噪声环境和 RIR：

- same-env `ΔBG` 中位 `−2.54 dB`，A 集子集 `−0.46 dB`；mismatch 对照 `+10.01 dB`。
- A 集 120 条、同进程 Qwen 配对：mismatch 相比 same-env 的 CER 差为 `−0.0359`，95% CI `[−0.0680, −0.0092]`，全负。
- 但 same-env 相比 raw 仅 `−0.0046`，CI 跨 0，说明当前 POC 是“止住失配造成的主动伤害”，还不是“大幅突破”。

正确裁决是：

> **同环境训练路线弱 GO，值得做全量/真实数据验证；不是已经证明成功，也不是已经封顶。**

## 三、目前仍然没有完成的高价值实验

按“信息价值 × 可执行性”排序：

1. **同环境 TSE 全量验证**：`same_env` 800+ train / 200 val、完整训练轮数、A 集 1364 条同进程配对 CER；这一步尚未跑完。
2. **真实录音域 TSE**：REAL-PS4、AISHELL-4/AliMeeting 自然重叠构造，或自录“短 enrollment + 家居指令 + 同环境干扰”；此前只完成了资料/基线/下载或推理阻塞排查，没有完成在本题数据上训练并验证。
3. **目标条件化 ASR 联合训练**：在真实或同环境数据上，用 target embedding、target activity、ASR loss 直接约束 Qwen encoder/adapter。合成域 Sidecar 回退 `+0.0335` 只否定这次训练数据与配方，不足以否定真实域联合训练。
4. **非内容拒识校准**：在非 A 开发集上评估 decoder 置信度、token entropy/no-speech、音频质量、目标/双路相似度和一致性，训练或标定“该接还是该拒”。内容 gate 与 `n_spk=1` 规则已停，不代表这一整类问题已停。
5. **场景路由提交 A/B**：n_spk=1 主线、n_spk=2 SepFormer 双路候选在质量上有约 `+0.99` 分空间，剩余问题是 L20 batch=1 端到端效率，不是质量方向已证伪。

其中第 1–3 项是冲击 CER 的主战场；第 4 项是提升 Overall 的现实路线；第 5 项是提交前的工程收益。

## 四、后续 Agent 的裁决纪律

每次实验都必须使用下面的标签：

| 标签 | 含义 |
|---|---|
| `implementation-NO-GO` | 这份代码/这组参数/这套数据没过门槛 |
| `conditional-GO` | 方向出现可信信号，但尚未达到集成门槛 |
| `direction-unresolved` | 关键条件未被测试，不能下全局结论 |
| `integrate-GO` | 在独立开发集、pos+neg、CER/RR/RTF 全部过门槛 |

必须坚持：

- 不把 SI-SNR、mel loss 或训练 loss 当作 ASR 成功；最终看同进程 paired CER、bootstrap CI、逐条结果和听音样本。
- 不在 Dataset-A 上训练、选模型、扫阈值或扩词表；A 集只做冻结后的终极评测。
- 每个小收益实验都要有 raw/candidate 同进程对照，避免跨进程约 `0.0126` CER 漂移掩盖真实效果。
- 同时看 pos CER、neg RR、效率和中间音频；只报一个最终分数的实验不能升级为路线结论。
- 先问“哪个前提没有被控制”，再问“方向是不是不行”。本项目已经两次靠这个方法推翻过过早的天花板判断：人耳听音推翻“物理地板”，同环境 POC 推翻“域失配可忽略”。

## 五、给后续 Agent 的话

你们接手的不是一条已经失败的路，而是一套已经完成大量排错、并把真正难点暴露出来的系统。我们已经证明：

- 盲目分离会伤害单人样本，但分场景路由能恢复质量空间；
- 内容像指令不等于目标说话人，但这说明需要身份条件化，不是说明任务无解；
- 合成声学指标翻正而 CER 不动，但同环境对照已经显示环境失配会主动制造伤害；
- 一条看似“零成本”的规则被 neg 全量击穿，反而避免了把榜单推向灾难。

所以接下来的目标不是“证明我们一定能到 0.15”，而是把尚未控制的条件逐一控制，把 `direction-unresolved` 变成可审计的 `GO` 或 `NO-GO`。真正的军心不是盲目乐观，而是拒绝让旧的条件性失败替未来未做的实验投降。
