# Dataset-A 全量评测、Phase-3 结论与下一步（2026-07-30）

## 1. 本轮结论

当前稳定提交线已经完成一次从原始 Dataset-A 音频开始的全量重跑。固定配置为：

- Qwen3-ASR-1.7B；
- 声纹阈值 `0.27`；
- `sim_only`，关闭 LLM；
- 关闭 DeepFilterNet3；
- 开启 `content_gate`；
- Qwen batch size 固定为 1；
- 本机 RTX 4060 Laptop 8GB。

Dataset A 在本轮中只用于最终测试，没有进入训练、checkpoint 选择或阈值调参。

按项目当前采用的全量字符累计池 CER，当前提交线估分为
`68.66–73.09 / 100`；如果 L20 效率腿接近满分，预计约 `73.09`。
如果主办方实际采用逐句 CER 平均，则估分降为 `64.54–68.97`。
因此，确认主办方 CER 聚合方法和效率映射仍是提交前的最高优先事项。

## 3. CER 口径澄清

`code/eval_datasetA.py` 当前输出的 `overall CER=0.7230` 是逐句 CER
算术平均。项目主报告、`CERMetric` 和历史 Qwen/场景路由结果使用的是
全量字符累计池：

```text
CER = 全部样本编辑错误数之和 / 全部参考字符数之和
```

本次累计池为 `5898 / 9512 = 0.6201`。旧离线值为 `0.6171`，
本次 Qwen 文本与旧全量产物一致率为 99.3%，差异只有 `0.003`，
不存在模型或推理链路回归。

交付、答辩和后续实验必须明确写出 `pool CER` 或
`per-utterance mean CER`，不能再只写 `overall CER`。

## 4. content gate 是否保留

content gate 在固定阈值 0.27 上：

- pos 额外误拒 35 条，累计池 CER `0.5966 → 0.6201`，
  CER 腿损失约 `0.94` 分；
- neg 多正确拒识 20 条，RR `90.51% → 94.73%`，
  RR 腿增加约 `1.69` 分；
- 净收益约 `+0.75` 分。

结论：当前提交线继续保留 content gate。禁止再用 Dataset A 扩词、
扫阈值或修改 gate 规则。

## 5. 场景路由候选

把已经冻结的场景路由规则与 content gate 离线组合，1350 条共同样本上：

| 系统 | 含 content gate 累计池 CER |
|---|---:|
| Qwen 主线 | 0.6168 |
| n_spk=1 主线；n_spk=2 SepFormer 双路 + heuristic | **0.5919** |

该候选可增加约 `0.99` 个质量分，但会增加 SepFormer 和双路 Qwen
开销。历史补跑中，574 条 SepFormer 分离 RTF 为 0.088；Qwen 日志使用
batch 16，不能代替官方 batch 1 效率结论。

结论：场景路由仍是唯一值得进入提交候选 A/B 的已有方案，但暂不直接
切换主线。2026-07-30 已接成 `submit_infer.py --scene-route` 可选开关：
只对 DiariZen 判为双人的样本运行 SepFormer 两路分离，固定 Qwen
`batch_size=1` 转写后用已冻结 heuristic 选路；单条分离失败回退主线，
默认关闭，不改变稳定提交配置。启用时必须让 `MODEL_SEPFORMER` 指向
已有本地缓存，代码不会隐式下载权重。

剩余只做：

1. 在 L20、batch 1 上跑端到端 pos/neg；
2. 若总分（质量增益减效率损失）仍为正，再决定集成；
3. Dataset A 不再用于路由规则或阈值选择。

## 6. Phase-3 Sidecar 最终结论

Phase-3 使用 AISHELL-1 官方 train 和 MUSAN，Dataset A 未参与训练或
选模。冻结 Qwen3-ASR-1.7B，前 8/24 层插入 rank-64 Sidecar，
可训练参数 1,427,521。

虽然 synthetic speaker-disjoint validation 的 ASR loss
`5.7891 → 4.0566`，但锁定 checkpoint 后一次性 Dataset-A 配对评测：

```text
baseline CER = 0.342948
Sidecar CER  = 0.376458
delta        = +0.033510
95% CI       = [+0.021655, +0.045744]
```

这是显著回退，Phase-3 判定为 NO-GO。不要租算力继续扩训，不集成
Sidecar，也不要用 Dataset A 反向调参。

## 7. 当前瓶颈和投入顺序

1. **多人重叠语音**：单说话人 transcribe CER 约 0.100，多说话人约
   0.518，是最大的识别差距。
2. **target presence / 声纹误拒**：1364 条 pos 中 644 条在阈值 0.27
   被拒，是当前含拒 CER 的主要损失；但任何改动必须在新的非 A 真实开发集
   上验证。
3. **场景路由效率**：固定路由有约 +0.99 质量分空间，是否进入提交取决于
   L20 batch-1 端到端 RTF。
4. **评测工程**：统一 CER 聚合口径，并让 Qwen 子进程回传真实峰值显存。

如果没有新的非 A 真实域开发数据，不再启动模型训练。近期投入应集中在
提交链可复现性、L20 效率、场景路由开关和最终格式验收。

### 7.1 解码期联合上下文补充实验

为避免重复 2026-07-24 已证伪的 Qwen 软 `context`，本轮实现了更保守的
声学 top-K 锚定短语偏置：固定通用家电词表的候选 token 只有进入原模型
top-20 时才获得 `+0.8` logits，不做 hard grammar，不改变声纹拒识。

在非 Dataset-A 的早期智能家居合成集上锁参后进行30条平衡烟测：

- baseline pool CER：`0.2989`；
- candidate pool CER：`0.2960`；
- ΔCER：`-0.0029`，未过预设 `-0.01` 门槛；
- 0% overlap：`-0.0133`，仅一条文本发生改善；
- 25% / 50% / 75% / 100% overlap：全部 `0.0000`。

判定为 NO-GO：不扩大、不扫参数、不在 Dataset A 验证、不接主线。该结论
只覆盖低成本解码期偏置；若未来获得匹配的非 A 真实域数据，训练式的
声学—语言联合适配器仍是不同路线。
