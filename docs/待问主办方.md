## 🔴 必问（决定 thr 最终值 + CER 数值）

### 1. 目标说话人(pos)是否必须转写、不允许拒？
- **为什么重要**：当前统一 thr=0.27 会拒掉 ~47% 的 pos 换 RR 腿。若赛规要求 pos 必须转写（拒=违规/0 分），thr 应→0（pos 全转写）。
- **已知不用问**：pos 被拒时算法上 CER=1.0（FAQ #8 已确认）；纯标准 CER 公式无"拒识额外惩罚"项。
- **问法**：pos 被系统拒识，是按 CER=1.0 计入，还是视为违规/该条 0 分？

### 2. 预处理口径（新增，比算法对齐影响更大）
算 CER 之前，是否对系统输出和标准答案做以下归一？
- **(a) 繁简**：繁体→简体？（不归一，繁体输出每字算错，CER 虚高 ~0.5）
- **(b) 数字**：ref 数字是中文"二十六"还是阿拉伯"26"？算 CER 前是否统一？（"26度" vs "二十六度" = 3 编辑，CER 0.75）
- **(c) 标点**：标点是否计入字符数 N？（Whisper 可能输出"，。"，ref 无标点）
- **(d) 英文混排**：英文幻觉字符是否计入 N？
