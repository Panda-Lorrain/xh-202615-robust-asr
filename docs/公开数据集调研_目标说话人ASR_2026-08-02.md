# 公开数据集调研：目标说话人 ASR / TSE（2026-08-02）

> 起因：用户质疑「目标说话人 ASR 领域有没有公开数据集？研究方向是否正确？一般来说领域都有人研究，不存在空白」。
> 方法：Web 调研（WebSearch + WebFetch），核实数据集语言/场景/可下载性/评测指标。
> 结论先行：**①方向 100% 正确；②有公开真实录制数据集；③我们之前自己合成走了领域公认有域 gap 的弯路。**

## 1. 一句话结论

**SLT 2026 REAL-TSE Challenge 几乎就是我们的题目**（真实录制 + 中英文 + 含家居场景 + enrollment + **中文 ASR 错误率 TER 评测**），且配套的 **REAL-T / REAL-PS4 真实录制数据集已公开或即将公开**。我们 TSE phase2 NO-GO + same_env 止跌的根因（合成数据域 gap）正是这个领域 2025–2026 在集体攻坚的痛点——**不是我们独有的问题，是我们用错了数据来源**。

## 3. REAL-TSE / REAL-T 生态详解（为什么是答案）

1. **评测指标含 TER（Token Error Rate）**：用 **Zipformer-ZH 中文 ASR**（`sherpa-onnx`）算，等价我们的 CER 腿——评测口径直接对齐。另有 F1（target 活跃区）+ SpkSim + DNSMOS。
2. **Baseline = BSRNN + ECAPA-TDNN**：与我们 WeSep pBSRNN + ECAPA/CAM++ 技术栈高度一致，迁移成本低。权重 Google Drive 公开（4 个模型）。
3. **数据构造方法天然解决域一致性**：从真实多说话人语料提取**自然重叠段**做 mixture + **同说话人 ≥5s 非重叠段**做 enrollment → 同一录音环境、同一说话人 → **天然 ΔBG≈0**。这正是我们 same_env 合成做不到、memory `a-set-is-real-recorded`/`tse-poc-weak-go-overturns-perception-gap` 推导出的「真人真实录制是唯一解药」——REAL-T 给了现成的公开语料 + 方法。
4. **源头论文坐实域 gap 是领域共性**：INTERSPEECH 2025《Real Conversational Mixtures for TSE》明确「TSE 在 LibriMix/WSJMix 合成上表现好，迁移真实对话会崩」。我们 TSE phase2 的「感知-识别鸿沟」误判，本质就是这个领域级问题。

---

## 4. 对我们项目的影响

1. **弯路识别**：Aishell+MUSAN+MIT-IR 合成 = REAL-TSE baseline 都标注有域 gap 的老路。TSE phase2 NO-GO、same_env 止跌、LoRA NO-GO 三连，根因都是「合成数据训 → 真实 A 集测」。全量特征对比（`fullfeat_report.md`）量化的 5 维 gap（时长/带宽/噪声质心/域一致性/SNR）就是这个弯路的声学指纹。
2. **正确路径**：改用 REAL-T / REAL-PS4 真实录制数据训 TSE → 天然同环境 → 跨越域一致性 gap（最大那维）。
3. **录真人不再是唯一解药**：之前 memory 结论「真人真实录是突破 same_env 天花板的唯一解药」现在有了替代——REAL-T 提供现成的公开真实录制语料 + 标准化构造方法，比自己从零录更高效、规模更大、可复现。

## 5. 风险与未知（诚实标注）

- **REAL-T dev set 发布状态**：GitHub 标 "to be released soon"，2026-08 是否已发需确认（`RickyQzh/REAL-T`）。
- **REAL-TSE EVAL-2 家居数据**：注册 2026-05-31 关闭，3000 对新采集真实数据（含家居/车内）拿不到。但 dev 源语料 + REAL-PS4 可用。
- **场景/enrollment 差距**：REAL-T 以会议/晚宴为主，家居是子集；enrollment ≥5s vs A 集 ~1.8s 超短——仍有 gap，但**远小于合成 gap**。
- **License / 参赛合规**：REAL-TSE challenge 数据条款、能否用于商业比赛训练提交，需查 license + 必要时问主办方（美的已确认允许外部公开数据训练，见 memory `external-training-allowed`，但 challenge 数据的二次使用条款要单独确认）。
- **精确交叉仍稀缺**：「中文家居短指令 + 超短 enrollment + 目标说话人 ASR」这个精确组合确实少，但**拼装现有真实录制资源 >> 从零合成**。
