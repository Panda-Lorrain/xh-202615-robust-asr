## 二、核心结论：合成-真人域 gap（结构性，非过拟合）

**调参降过拟合反而更差** → 证伪了"v1 是过拟合"的假设：
- 如果是过拟合，v2 降过拟合该改善 A 集
- 实际 v2 loss 没降到位（0.92，过拟合确实缓解）但 A 集更差（+0.14 vs +0.035）
- → 真根因是**合成域（CosyVoice 声纹 + 合成 babble）vs 真人域（A 集录音）的结构性 gap**

**LoRA（纯 ASR，无 enrollment）路彻底封死**。模型在合成域不管学得好（v1 过拟合）还是学得一般（v2 欠拟合），都偏离真人域，A 集都退化。

## 三、三层墙诊断（cascaded + 通用 ASR 框架 CER 攻不动的根因）

本项目 18+ 路 CER 攻坚尝试全部 NO-GO，共同根因是三层结构性墙：

1. **感知-识别鸿沟**：声学/SI-SNR/mel/loss 的改善**不传导到 ASR CER**。
   - TSE：SI-SNRi +2.26dB、mel −31%、wave −43%（声学全面翻正），CER 纹丝不动
   - LoRA：loss 降到 0.42（模型学会合成数据），A 集 CER 反退化
   - 印证 EoW 论文：Whisper 类 ASR 的错误在"识别决策"不在"听不清"

2. **A 集死区是物理地板**：78.8% 样本 sim<0.4，target 信号被 babble −5dB 物理淹没。
   - SOTA 云端大模型（MiMo）在死区都只能 0.417
   - 信息论极限，分离/微调都救不了（信号已丢）

3. **架构不匹配**：Qwen3-ASR 是**通用转写器**，不认识"谁是 target"。
   - LoRA 改的是"转写能力"，没碰"选 target 能力"
   - 而题目瓶颈恰恰在"选 target"（重叠区选错人 → CER 炸）
   - enrollment（1.8s 唤醒音频）在 cascaded 里被降级成"外部 sim 选路"，没参与识别决策

**所有尝试都在攻非瓶颈层**（声学质量/语言知识），瓶颈在"选 target + 死区信号丢失 + 识别决策"——数据/微调/分离/后处理全碰不到。

## 五、下一步：B vs C 决策（待用户定）

### B：端到端 Phase-3 完整版（攻 CER，高风险高回报）
**做什么**：改造 Qwen3-ASR，让 enrollment 从"外部选路"升级为"内生参与识别"：
1. Speaker encoder（复用 CAM++/wespeaker）：enrollment 1.8s → 192d embedding
2. 注入机制：FiLM（每层 scale/shift，简单先做）或 cross-attention（强但复杂）
3. 冻结 Qwen3 主体 + 只训 speaker encoder + 注入模块（新增参数 <5–10%）
4. **ASR loss（CTC/CE）直接反传** ← 这是和之前 Phase-3 POC（0.376 退化）的关键区别，不再优化 SI-SNR/mel 代理
5. 数据扩量：1k → 10k+（D 盘 100G + 租 L20）

**为什么是唯一出路**：唯一能碰"墙 3（架构不匹配）"的路。enrollment 内生注入 → 模型认识 target → 攻题目本质。其他 18 路全碰不到。

**算力/时间**：L20，6-8h/round，~64 元/round，3-5 round 调参，总 <500 元。
**GO 门槛**：A 集 ΔCER ≤ −0.05（同进程配对，bootstrap 95% CI 上界 <0，07-29 教训）。
**风险**：仍可能 NO-GO（感知-识别鸿沟第 5 证），但即使失败也是答辩强弹药（"我们做了端到端 POC"）。

### C：归档转腿（稳，低风险）
**做什么**：接受 cascaded CER 到顶（16.26/40，模型 ~67-70 分），转其他腿：
- **效率腿 20%**：租 L20 测真实 RTF + 总分（本机 4060 测不了）
- **答辩腿**：把 18+ 路系统性证伪做成答辩主线——"穷尽 cascaded + 通用 ASR 的能力边界，精确定位三层结构性瓶颈，指明端到端 enrollment-aware 架构的必要性"。这是真新颖性 + 真诚实归因。
- **RR 腿**：已到顶 ~38。

### 建议
取决于用户的**算力/时间预算 + 风险偏好**：
- 有 L20 + 几周时间 + 愿赌 → B（唯一攻 CER 的路，赌赢上游争冠）
- 时间紧 / 不想赌 → C（稳住现有 + 效率 + 答辩，在"普通队伍"里争上游）

**关键判断**：大概率（70-80%）没有碾压级队伍（A 集物理地板对所有人公平 + 端到端 TS-ASR 是 Interspeech 2025 前沿，多数队伍做不出来）；小概率（20-30%）有端到端强队。所以 C 不一定输，B 是"做那个少数派"的赌注。

## 六、红线 + 教训（必须遵守）

**红线**：
- Dataset-A **绝不进训练**（含提取背景噪声 = 泄漏）；只允许 A 集外数据（AISHELL/MUSAN/MIT/WHAMR/DNS）
- 训练产物固化进权重，推理零外部依赖（CosyVoice 只用于造数据，不进提交链）
- speaker-disjoint train/val；大批量 wav 不入 git

**教训**：
- **小收益实验必须同进程配对**（07-29：Qwen 跨进程有 +0.0126 CER 漂移）—— 本 POC eval 已同进程
- **SI-SDR 尺度不变陷阱**：separator 输出 RMS 可达 mixture 数倍，overlap 拼接必须显式 gain matching
- **stdout 缓冲**：后台训练脚本 print 不 flush，要靠 train_log.json / GPU util 判断进度，别误判卡死
- **域 gap 不可低估**：合成数据再逼真，LoRA/微调都会被合成-真人 gap 卡，第 4 次证伪
